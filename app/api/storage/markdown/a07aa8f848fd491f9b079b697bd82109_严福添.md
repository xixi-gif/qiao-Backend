# 严福添：从海员到大副的桑梓情怀
严福添，又名福财，在20世纪30年代初期成为一名海员。凭借自身的聪明才智与勤奋刻苦的精神，他逐步晋升，最终担任香港一船务公司的“大副” ，在事业上取得成功。

事业有成后，严福添心系家乡，不仅捐资并发起族亲建起严氏祖祠，还建设了私塾和房屋，成为东湖第一栋号称“别福添别墅”的主人，以实际行动回馈故土，展现出浓厚的桑梓情怀。
