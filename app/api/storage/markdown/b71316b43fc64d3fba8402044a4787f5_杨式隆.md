# 杨世隆侨乡故事

## 人物背景
**杨世隆**（1905-1983），广东潮安人，著名泰国侨领：
- 出生于贫苦农民家庭
- 16岁随"红头船"南渡暹罗（今泰国）
- 从苦力成长为实业家
- 被誉为"潮侨三杰"之一

## 创业历程
### 初期奋斗（1921-1935）
1. **码头苦力**：在曼谷码头扛米包
2. **小商起步**：经营潮州杂咸（腌制食品）
3. **创办隆都行**：专营暹罗大米出口

### 事业腾飞（1936-1949）
- 建立**暹罗米业公会**
- 开拓香港、新加坡市场
- 抗战期间组织侨胞捐款支援祖国

## 突出贡献
### 对侨居地
- 创办泰国首个潮州商会
- 兴建华人医院、学校
- 调解劳资纠纷，促进社会和谐

### 对家乡
1. **基础设施建设**：
   - 捐建潮安第一所侨校
   - 修筑"世隆路"（连接8个村庄）
2. **经济支持**：
   - 1943年饥荒时运粮回乡
   - 投资潮汕首批侨资企业
3. **文化传承**：
   - 资助重修开元寺
   - 保存潮剧传统剧目

## 精神遗产
- **"三刀精神"**： 
  - 菜刀（餐饮业起家）
  - 剪刀（成衣业拓展） 
  - 剃刀（服务行业深耕）
- **家训**："发达不忘唐山地，富贵当念韩江水"

> 注：该故事典型反映了"潮汕华侨三重性"——在侨居地发展、为祖国出力、帮家乡建设。
