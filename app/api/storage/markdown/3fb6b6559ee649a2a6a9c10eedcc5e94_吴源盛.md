# 侨胞吴源盛：马来西亚的商界翘楚，潮团事业与家乡发展的有力推动者

## 基本信息

- **出生日期**：1962 年
- **出生地**：马来西亚霹雳州怡保
- **籍贯**：广东普宁
- **职务**：马来西亚潮州工商总会总会长、马来西亚潮州公会联合会永远名誉主席、国际潮商经济合作组织执行会长

## 早年经历

吴源盛是第三代马来西亚潮汕人，1962 年在马来西亚出生，是家中 8 名兄弟姐妹中的第六个。他从小受到家中长辈的良好教育，五六岁时，祖父常带他去寄番批，让他从小就知道家乡在潮汕。由于幼时家境清贫，为改善生活，他十五六岁时经常到当地的潮州会馆打乒乓球。

## 职业生涯

- **创业历程**：吴源盛大学主修机械工程，毕业后先后从事五金、建材批发的销售员及公司经理，之后开始创办自己的企业。创业初期，资金有限，他身兼多职，既是老板又是促销员、秘书。慢慢地生意上了轨道，他抓住时机扩大生意版图，涉足五金贸易、物业发展、建筑、水泥、海鲜批发等行业，并取得巨大成功。
- **企业现状**：现任森源机构董事经理及诺华集团董事经理。

## 社会贡献

- **社团贡献**：吴源盛从十五六岁开始参与社团活动，年轻时加入在马来西亚华人社会中具有影响力的霹雳韩江公会青年团，并从基层做起。他先后担任马来西亚潮州公会联合会青年团总团长、马潮联会常委及副主席等职，2004 年出任霹雳韩江公会会长，2012 年当选为马潮联会主席。他积极推动潮汕文化传承，鼓励年轻人参与社团活动。2024 年 11 月，吴源盛担任第十二届国际潮青联谊年会大会联合主席，推动潮汕文化传承与发展。
- **教育支持**：吴源盛经常赞助华文独立中学教育，他领导的马潮联会积极在潮属会馆中推动潮语教学，制作光碟教小孩子讲潮州话，还在国际上推广潮语。
- **文化推广**：他积极推动潮语传承，认为语言是文化之根，通过制作光碟等方式，在马来西亚国内外推广潮州话。

## 祖籍与家乡联系

吴源盛的祖籍地在潮汕，他对家乡有着深厚的感情。2014 年初，为支持汕头争取将华侨经济文化合作试验区列为建设 21 世纪 “海上丝绸之路” 的国家级示范平台，他与海内外知名侨领一同联名致信中央和国家领导人，表达了期盼参与 “海上丝绸之路” 建设的热切心愿。他还表示，海外华侨的心里只认一个 “大潮州”，“大潮州” 好就是家乡好，参与并支持汕头新一轮的发展是义不容辞的责任。

## 荣誉与影响

吴源盛凭借其在商业、社团及文化传承等方面的杰出贡献，成为潮汕侨胞中的重要人物，他的事迹和精神激励着众多潮汕后人，为传承和弘扬潮汕文化、促进中马友好交流做出了积极贡献。
