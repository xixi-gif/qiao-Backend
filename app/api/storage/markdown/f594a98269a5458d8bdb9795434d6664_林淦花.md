# 林淦花：助力潮人事业，推动中美文化交流
林淦花，广东省潮汕人。她是美国食用油厂总裁，现任美国南加州华人社团大联盟主席团主席、美国东方文化联谊会会长、世界越柬寮华人团体联合会共同主席、美国潮商总会共同主席、美国南加州潮州会馆常务顾问、中国侨联第十届海外委员、江苏省海外交流协会第五届理事会常务理事、深圳市侨联荣誉主席、汕头市海外交流协会名誉会长等职。

## 一、在美经历
1. **积极参与社团活动**
    - 林淦花是洛杉矶华埠活跃的知名侨领，在南加州潮州会馆、美国潮商总会等都担任要职。2016年，美国东方文化联谊会与多家华人社团发起成立美国南加州华人社团大联盟，得到近百家华人社团的响应。
    - 2022年11月23日，美国南加州华人社团大联盟于洛杉矶艾尔蒙地会所举行感恩节餐会，林淦花主席发布人事任命，特聘多位人士为美国华人社团大联盟共同主席、副主席、副秘书长等。
2. **促进中美文化交流**
    - 林淦花一直致力于促进中美两地的文化交流。2019年10月，美国东方联谊会的多名潮剧演员在汕头潮剧文化周上表演了《五洲同歌》《三辩本》等精彩剧目；11月，美国东方文化联谊会又与中山潮人海外联谊会共同举办“奋斗共筑，五州同歌”潮剧联欢晚会，传承优秀中华文化，激扬新时代奋斗精神。
3. **支持祖国建设**
    - 林淦花爱国爱家，多次用实际行动支持祖国。2019年10月，她作为海外侨胞代表应邀参加建国70周年阅兵观礼及相关庆祝活动。她还组织策划庆祝中华人民共和国成立70周年暨中美建交40周年大型交响合唱音乐会，带领美国南加州华人社团大联盟争当祖国护旗手，以美国南加州华人社团大联盟主席名义登报支持一国两制。
    - 自2014年起，林淦花每年都会与国家同步，在加州当地大力组织众多爱国侨胞，开展“南京大屠杀死难者公祭日”纪念活动，举行“勿忘国耻”大型文艺演出等。
4. **助力家乡汕头发展**
    - 林淦花关心家乡汕头的发展，2021年向第三届亚洲青年运动会捐赠饮水机。她还积极推动汕头与海外的交流合作，向海外侨胞宣传汕头的投资环境、美食文化等特色产业，讲好家乡故事，做好侨的文章，为汕头高质量发展、乡村振兴贡献力量。
5. **热心公益事业**
    - 林淦花乐善好施，热衷公益事业。每当自然灾害来临，她都时刻牵挂故土灾情，慷慨解囊，踊跃捐助。她也经常带领侨胞们为残疾儿童提供救助，献上海外华人华侨的一片爱心。
    - 2020年，中国武汉发生新冠病毒疫情期间，林淦花和大联盟的干部们第一时间发起爱心筹款活动，将捐款购买的防护物资及时送往中国灾区，获潮州市新型冠状病毒感染的肺炎疫情防控指挥部办公室颁发的“防控疫情、大爱无疆”奖牌。

## 二、对中美两国的贡献
1. **促进中美贸易往来**
    - 林淦花积极响应“一带一路”倡议，广泛团结海外侨胞，为促进中美两国贸易文化互动交流做出了重要贡献。她带领美国南加州华人社团大联盟为中美经贸合作牵线搭桥，推动双方在贸易、投资等领域的合作项目落地生根。
2. **推动中美友好关系发展**
    - 2023年11月19日，林淦花率领南加州华人社团大联盟百人团赶赴旧金山欢迎习近平主席与美国总统拜登会晤。她表示海外侨胞期望中美两国恢复正常的两国关系，和平共处，相互尊重，合作共赢，维护世界和平。

林淦花女士作为美国知名潮籍女企业家和侨领，始终将爱国视为自己的崇高信仰，致力于促进中美两国的文化交流与友好合作，为潮人事业和家乡发展做出了卓越贡献。
