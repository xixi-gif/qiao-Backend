# 杨启秋：柬埔寨华社杰出领袖

## 一、个人背景
1. **出生信息** ：1944年，杨启秋出生于柬埔寨磅湛省，祖籍广东潮安。
2. **少年经历** ：少年时期，杨启秋曾在中国求学，接受系统的教育。

## 二、商业成就
1. **经营生意**
     - **小买卖与海运起步** ：学成后的杨启秋回到柬埔寨开始经营生意，从做小买卖、跑海运起步，凭借敏锐的市场洞察力和勤奋努力，逐渐积累了财富和经验，为后续的商业发展奠定了基础。
     - **抓住战后机遇** ：20世纪70年代，柬埔寨陷入战争，杨启秋抓住战后物资短缺的契机，从事进出口贸易，并因此大赚一笔。
     - **投资房地产** ：1986年间，金边地产出现波动，杨启秋又果断投资房地产，进一步扩大了自己的商业版图。目前，他拥有冠霖国际集团，旗下包括多家大公司，涵盖货仓工业、建筑、农业、彩印、餐厅、报关运输、经济免税特区、化肥和贸易等产业。

2. **创办《柬华日报** ：
     - **创刊背景** ：2000年，杨启秋主持创刊出版了《柬华日报》。
     - **报纸作用** ：该报纸成为柬华理事总会的机关报，为传播华文教育、弘扬中华文化、促进中柬友好交流发挥了重要作用。

## 三、潮社事业贡献
1. **复兴潮州会馆**
     - **多方筹措** ：1993年，柬埔寨战后和平曙光初现，杨启秋发动潮籍乡亲多方筹措，使毁于战乱的柬埔寨潮州会馆得以重建。
     - **担任会长** ：杨启秋荣任历届会长，带领广大潮籍乡亲致力于华社华人各项事业。
     - **推动华文教育** ：在他的努力下，潮州会馆旗下的端华学校成为东南亚规模最大的华文学校之一，培养了大批兼通中柬文化的优秀人才，为中华文化的传承和潮人优良传统的延续做出了重要贡献。

2. **推动华文教育**
     - **恢复华文教育** ：在杨启秋的努力下，柬埔寨的华文教育因战乱中断20多年后逐渐恢复发展。
     - **学校规模与影响** ：柬埔寨现有华校70多所，仅杨启秋亲自创办的金边端华学校就有1.4万多名学生。华文学校的蓬勃发展不仅很好传承和弘扬了中华文化，而且为柬埔寨国家建设培养了大批的人材。

3. **担任多项职务**
     - **多个重要职务** ：杨启秋生前担任柬埔寨柬华理事总会永远名誉会长、柬埔寨潮州会馆会长、《柬华日报》董事长、全球董杨童宗亲总会第六届理事长等职务。
     - **服务华社** ：他长期服务华社，大力支持柬埔寨华文教育，弘扬中华文化，资助慈善公益事业，为推动华社和谐发展、促进中柬友好作出了重要贡献。

## 四、社会荣誉
1. **勋爵爵位** ：1994年，柬埔寨国王授予杨启秋勋爵爵位。
2. **“国家卫士金质勋章”** ：2002年，柬埔寨王国政府总理授予杨启秋及其夫人勋爵“国家卫士金质勋章”。
3. **“海外热心华文教育人士奖”** ：2011年，他荣获中国国务院侨务办公室授予“海外热心华文教育人士奖”。

## 五、亲属情况
1. **家庭成员** ：杨启秋膝下育有4个儿子，分别是杨宗勋、杨宗霖、杨宗顺和杨宗财。
2. **儿子成就** ：其中，杨宗勋是柬埔寨王家军三星上将。

杨启秋的一生，是为柬埔寨华人华社事业和中柬友好交流不懈奋斗的一生。他以传承民族精神、弘扬中华文化为己任，团结带领华社精英，为振兴全柬华文教育事业鞠躬尽瘁，为战后柬埔寨华人华社事业的复兴和发展作出了历史性贡献。他毕生对发展华人华社事业、促进柬中传统友好作出了不可磨灭的功勋，其贡献得到了中柬两国政府和华社的高度评价和赞誉。2018年2月21日，杨启秋与世长辞，享寿积闰77岁。
