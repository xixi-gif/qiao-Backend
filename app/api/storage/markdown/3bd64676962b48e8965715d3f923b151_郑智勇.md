# 郑智勇：暹罗侨领的传奇人生

## 人物背景
**姓名**：郑智勇（1851-1937）  
**别名**：二哥丰  
**籍贯**：广东潮安县凤塘镇淇园乡  
**身份**：暹罗（泰国）著名侨领、实业家、慈善家

## 早年经历
1. **贫苦出身**  
   - 生于1851年，幼年家贫
   - 14岁随"水客"偷渡暹罗谋生

2. **艰苦创业**  
   - 初在曼谷码头当苦力
   - 后经营航运、碾米等产业

## 事业成就
**商业帝国**：
- 创立"智勇轮船公司"
- 开办碾米厂、钱庄
- 垄断暹罗赌业（获王室特许）

**社会地位**：
- 被暹罗王室封为"坤拍"（高级爵位）
- 成为暹罗潮州会馆创始人之一

## 爱国事迹
1. **支持革命**  
   - 资助孙中山革命活动
   - 同盟会暹罗分会主要支持者

2. **建设家乡**  
   - 1905年回乡创办"智勇学校"（潮汕最早新式学堂之一）
   - 修建潮汕铁路
   - 捐资修筑韩江堤防

## 传奇故事
**"二哥丰"称号由来**：
- 因排行第二且乐善好施
- 暹罗民间尊称"二哥丰"（"丰"即富裕之意）

**与孙中山的交往**：
- 1903年首次接待孙中山
- 多次资助革命经费
- 其商行成为革命党秘密联络点

## 历史评价
- "暹罗华侨领袖第一人"（《泰国华侨志》评）
- 潮汕侨乡建设的先驱者
- 近代中泰友好交流的重要桥梁

> **文化影响**：  
> 郑智勇故事已成为潮汕华侨文化的象征，其事迹在泰国潮裔社区广为流传，在潮汕地区建有纪念馆和多处纪念设施。
