**潮州杰出爱国华侨艺术家陈天啸的故事**

陈天啸（1898～1978），著名国画家，潮州城区（今湘桥区）人。他的一生充满了艺术的追求与爱国的情怀，成为潮州乃至中国美术史上的重要人物。

**早年与艺术天赋**

陈天啸从小酷爱丹青，天赋甚高，力学不倦。他不仅学习书画，还师从家乡文学专家林幼梅攻读古典诗词，学有所成。青年时代就名闻桑梓，时人称其诗、书、画、琴“四绝”。

**艺术成就与国际声誉**

**上海美专教授**

民国18年（1929），陈天啸被上海美术专科学校聘为国画系教授。他以精湛的书画艺术和丰富的教学经验赢得学生的拥戴，桃李满天下。当代潮汕著名画家刘昌潮等一批名家都曾在上海美专学习过，师承其门下。

**东南亚与欧洲的画展**

民国24～33年，陈天啸旅居东南亚诸国，曾在印尼、缅甸、新加坡、泰国、马来西亚、印度、菲律宾、越南、意大利、法国、瑞士等国家举办过个人画展，受到各国观众及华侨的热烈欢迎，被誉为诗、书、画、琴“四绝”。他在罗马举办画展时尤为轰动，当时的意大利报纸评论：“日本以帝国的名义，经一年的筹备，在罗马开了一个画展。画展宣称，中国自宋南渡以后已没有了艺术，因艺术已跑到日本来发展了。怎知，看过陈君的画展以后，才知艺术还在中国。并且，我国（指意大利）以后说到‘艺术’两字，不能不予中国以最大的注意。”

**归国后的艺术探索**

民国34年归国定居后，陈天啸在花鸟画方面不断探索，精益求精。他画的梅花曾两次获全国第一届、第二届画展一等奖。

**爱国情怀与贡献**

**抗日战争期间的募捐**

陈天啸是一位杰出的爱国华侨艺术家。抗日战争期间，他把办画展和卖画的大部分收入捐赠给宋庆龄、何香凝领导的全国妇女协会、抗日救国后援会等爱国团体和难民。按当时的米价，捐赠的款项可购大米7000多斤。蔡元培曾为其画展题词：“国难方殷，全民负责。各尽所能，得寸得尺。孰云艺术，无补时艰。觥觥义举，矜式时贤。”

**社会贤达的题词赞誉**

社会贤达多有题词推崇赞赏。林森题词：“爱国精神。”于右任题词：“艺术救国。”叶恭绰先生题词：“邦家之光。”

**艺术风格与代表作品**

**画作题材广泛**

陈天啸的画作题材内容涉猎广泛，人物、山水、花鸟、蔬果、禽兽鱼虫，无所不现。他的艺术表现上落笔不俗，有些已至化境，从笔墨构图到意境传神方面看，毫不逊色于上海及岭南诸名家。

**代表作品**

- **《踏春图》（1958）**：规格52X108，表现梅兰竹菊，表达苏世独立的清高情怀。
- **《六祖撕经图》（1962）**：规格67X132，人物画，传递出疏狂旷放之意境。
- **《钟馗》（1958）**：规格34X68，人物画，展现了陈天啸的禅意画风格。
- **《墨荷》（1959）**：规格86X174，表现荷花的残荷之美，泼墨重彩的大写意笔法。

**书法成就**

陈天啸的书法以汉隶为宗，间或行草书，对清代书法家伊秉绶情有独钟，用笔刚健挺拔、沉稳大度、拙中寓巧。

**晚年与身后荣誉**

**晚年经历**

上世纪30至40年代，陈天啸的国画艺术饮誉海内外，直至50年代初，他在花鸟画方面仍保持一流水平。1957年他被错划为右派分子，从此在画坛上匿迹三十年。“文革”期间又遭劫难，被强迁至山东惠民固源沾化生产大队劳动改造。1978年陈天啸终因久久含冤积劳成疾而病故。

**身后荣誉**

1990年10月，在潮州市博物馆、汕头画院和画家的家乡庵埠镇举办了“著名归侨画家陈天啸遗作展”。中国美术家协会主席吴作人为画展题签，全国侨联名誉主席张国基老人为画展题词：“艺苑珠玑”，广东省政协主席吴南生题词：“笔留岭海，情满九洲”。2008年8月，深圳举办了陈天啸遗作展并出版《陈天啸作品集》大型八开画册。2009年，陈天啸遗作在上海展出。人们盛赞这位在上世纪三、四十年代就保持一流水平画家的艺术，崇敬画家的爱国情怀以及高尚人品和画品的统一。

**结语**

陈天啸的一生，是一个以毕生精力执着于丹青绘事的人，也是一个历经坎坷却不改赤子情怀的爱国华侨画家。“胸贮五岳，饱经风霜”正是画家陈天啸的人生写照。他的艺术伴随着他的精神将永远为世人所纪念。石涛有诗云：“画笔传神总是春”。欣逢中华盛世，陈天啸先生一生为之奋斗追求的艺术，重新焕发出春的气息、春的风彩的日子已为期不远矣！
