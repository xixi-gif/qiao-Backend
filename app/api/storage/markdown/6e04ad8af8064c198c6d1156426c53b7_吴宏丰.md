吴宏丰

__吴宏丰：侨领的家国情怀与慈善之路__

__一、潮汕根脉，拳拳赤子心__

1931年，吴宏丰出生于泰国曼谷市民武里县，然而他的根脉深植于潮汕大地，祖籍潮阳四区胪溪乡（今属潮南区胪岗镇）。他自幼天资聪颖，勤勉好学，七岁那年，被父亲送往汕头老家求学，开启了他的学业之路。在汕头的日子，他不仅接受了传统的中华文化教育，更是在心中种下了对故乡的深深眷恋。然而，命运多舛，第二年日寇侵华，他无奈辍学回到泰国。尽管如此，他在泰国继续接受华文、泰文教育，奠定扎实的中、泰、英文基础。

吴宏丰先生幼年家教甚严，从小立志干一番事业，报效乡邦。他先后进过泰国华文学校、泰文学校学习，中、泰、英文颇有根底。吴宏丰先生继承了父亲经营火砻业（碾米），他诚信待人，是非分明，处事积极，才华卓著，且勤奋不辍、筹谋有方，不断发扬光大，逐步奠定了庞大的事业基础。

__二、实业报国，逐梦商海__

青年时期的吴宏丰继承了父亲经营的火砻业，他个性豪爽，光明磊落，眼光远大，诚信待人、处事积极、才华卓著、是非分明，且勤奋不辍、筹谋有方，所主持之房地产建筑业与筑路等各种建设工程，深受泰政府有关部门之信赖。他不断把业务发扬光大，遂奠定了庞大的事业基础。

吴宏丰事业有成，秉性豪爽，热心公益，乐善好施，泽被社会。多年来，在泰国和祖国大陆，为各种公益捐巨资。他在任职泰国吴氏宗亲总会理事长期间，为建造泰国吴氏大宗祠，联合宗亲举行会议，率先捐款二千万铢，吴氏领袖纷纷解囊，一日之间集资一亿余铢。他还出资重建千年祖祠两座，为家乡宗亲提供弘扬祖德、敦睦宗族的场所。

__三、情系桑梓，捐资助学__

吴宏丰先生对家乡的教育事业尤为关注。他在家乡的捐资建校之举，成为当地佳话。他捐资兴建了潮阳市吴宏丰妇婴医院、胪溪小学大礼堂“锦河堂”、“福顺楼”，在上厝学校捐献大礼堂全座，命名为宏丰堂、楚璇楼，以及楚璇科技教学楼、教师宿舍楼等。他还发动旅泰宗亲捐资兴建“胪溪教育村”，亲任“胪溪教育村”主任，并捐资成立教育基金会。他的善举不仅改善了家乡的教育条件，更为无数学子点亮了知识的灯塔。

__四、大爱无疆，慈善为怀__

吴宏丰先生的慈善事业不仅限于教育领域，更广泛涉及医疗、扶贫、养老等多个方面。他在家乡捐办自来水厂，使村民饮食用水卫生纯净；修筑老寨道路，铺设村道水泥路；独资兴办村老人院丰怡园；捐资扶持家乡特困村民；疏浚老溪，重修老寨门桥。在泰国民武里县，他是民巴塞学校的长期资助者，曾捐资泰币1000万铢，为泰国潮州会馆辖下弥博中学扩建校舍；捐资泰国卫生部辖下的空郡地区诺帕叻医院价值数百万铢的医疗设备；捐资1000万铢装修朱拉隆功医院门诊楼。

2008年，四川汶川大地震发生后，吴宏丰宗长积极捐款五百万泰铢，以表达对灾区的关切之情。2011年，他捐款25万元帮扶汕头潮南胪岗后安村贫困户，并捐资1800多万元续建潮南吴宏丰医院。2018年，吴宏丰宗长向泰国道德善堂捐赠善款10万泰铢，支持“捐赠医疗器材”计划。此外，他还在2019年5月30日向中国外交部定点扶贫项目云南省麻栗坡县和金平县捐赠了1000万泰铢。

__五、侨领风范，德高望重__

吴宏丰宗长在泰国担任多项重要职务，如泰国中华总商会会长、泰国吴氏宗亲总会理事长、旅泰胪溪吴氏家族会理事长等。他积极促进泰中两国的友好交流与合作，为泰国的经济社会发展和华社的团结进步做出了卓越贡献。他致力于推动华文教育的普及和传承，私人斥巨资向全泰国一百三十多所需建校经费的华文民校每校赞助一百万泰铢。此外，他还在2008年北京奥运会火炬传递仪式中担任第一棒火炬手，展现了他的爱国情怀和对祖籍国的支持。

吴宏丰博士是泰华侨社德高望重的侨领，著名慈善家，仁慈博爱，慷慨大方。他连续多年捐款赞助泰国崇德善堂，支持善业，殊堪褒扬。他委派令长孙男吴和荣于近日再次前往泰国崇德善堂捐赠十万铢善款，热心支持善堂开展慈善工作，崇德善堂董事长李振钦代表全体董事向永远荣誉董事长吴宏丰博士长期捐赠善款的义举致表谢意和崇高敬意。

__六、俭朴生活，高尚情操__

尽管在事业上取得了非凡成就，吴宏丰先生个人生活却非常俭朴。他平日里很少上酒楼，回汕期间也从未宴请他人，亲友聚餐多为简单饭菜。在“非典”时期，他到北京开会，一日三餐几乎都在路边小食店解决。他喜欢北京的风味小吃，却也有人认为他是为了节省开支。一次与妻子在餐厅就餐后，他将剩菜打包带走，展现出良好的节俭习惯。

吴宏丰先生的一生，是奋斗的一生，是奉献的一生。他用自己的行动诠释了侨领的担当与责任，用爱心和善举温暖了无数人。他那深沉的家国情怀和高尚的道德情操，成为后人学习的楷模，激励着一代又一代的潮汕人和海外侨胞。
