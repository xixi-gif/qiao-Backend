# 谢镕仁

## 一、基本信息

  * **姓名**：谢镕仁
  * **出生日期**：1967 年
  * **出生地**：泰国
  * **籍贯**：广东汕头澄海
  * **职称**：正大集团首席执行官
  * **家族背景**：泰籍华裔，正大集团创始人谢国民的三子
  * **教育背景**：毕业于美国波士顿大学，主修财务管理，获工商管理学士学位。2016 年，获得泰国 Ramkhamhaeng 大学大众传播博士荣誉学位。

## 二、家族背景

  * **祖父**：谢易初，正大集团的创始人之一。
  * **父亲**：谢国民，正大集团资深董事长。
  * **兄弟姐妹**：长兄谢吉人（正大集团董事长），二兄谢汉人。

## 三、职业生涯

  * **早期经历**：谢镕仁毕业后进入正大集团，从基层做起，积累了丰富的企业管理经验。
  * **True Corporation 职业生涯**：
    * 1999 年，出任 True Corporation 总裁、首席执行官。
    * 2004 年，带领 True Corporation 成功重组和改革，使其发展为亚洲领先的电信公司之一。
    * 2013 年，在泰国发起并成立第一个电信基础设施基金 —— 数字基础设施基金（DIF），这是 True Corporation 和电信行业的重要里程碑。

  * **正大集团 CEO**：
    * 2017 年，谢镕仁接任正大集团首席执行官一职，成为正大集团第三代领导人之一。
    * 在其领导下，正大集团继续拓展农牧食品、批发零售、电信电视、金融、地产、机械加工等多元化业务，2023 年全球销售额达 970 亿美元。

## 四、商业成就

  * **True Corporation**：在谢镕仁的领导下，True Corporation 成为泰国领先的电信公司之一，提供移动电话、固定电话、宽带和付费电视等服务，并在泰国证券交易所上市。
  * **正大集团**：谢镕仁接任 CEO 后，推动正大集团的全球化发展，进一步巩固了其作为全球最大华人跨国公司的地位。

## 五、社会贡献

  * **社会职务**：谢镕仁担任多项社会职务，如联合国全球契约网络泰国筹备委员会主席、泰国政府教育改革独立委员会成员、泰国数字经济与社会委员会主席等。
  * **抗疫贡献**：2020 年，谢镕仁被任命为泰国政府新冠肺炎疫情管理中心顾问委员会成员，为泰国的疫情防控和经济复苏贡献力量。

## 六、个人财富

  * **家族财富**：谢镕仁所在的谢氏家族蝉联泰国首富宝座十余年，在福布斯 2024 泰国富豪榜上，谢氏家族的财富高达 300 亿美元。

## 七、个人生活

  * **婚姻家庭**：谢镕仁已婚，育有一子一女。他注重家庭生活，积极参与家庭活动。
  * **兴趣爱好**：谢镕仁热爱运动，尤其喜欢打高尔夫球和网球。这些运动不仅帮助他保持身体健康，也成为他与商业伙伴交流的重要方式。
  * **慈善事业**：谢镕仁积极投身慈善事业，多次为教育、医疗等公益项目捐款。他相信通过教育可以改变人的命运，因此特别关注贫困地区的教育发展。

## 八、商业哲学

  * **创新与变革**：谢镕仁深知在快速变化的商业环境中，创新和变革是企业发展的关键。他鼓励员工勇于尝试新事物，不断探索新的商业模式和技术应用。
  * **可持续发展**：他认为企业不仅要追求经济利益，还要注重社会和环境的可持续发展。因此，正大集团在经营过程中积极推行环保措施，支持绿色农业和清洁能源项目。
  * **人才发展**：谢镕仁重视人才培养，认为人才是企业最宝贵的资产。他推行了一系列人才培训和晋升计划，为员工提供广阔的发展空间。

## 九、商业创新

  * **数字化转型**：谢镕仁积极推动正大集团的数字化转型，利用大数据、人工智能和物联网等技术提升企业的运营效率和市场竞争力。正大集团在多个业务领域引入了先进的数字化管理系统，实现了业务流程的自动化和智能化。
  * **多元化发展**：除了传统的农牧食品和批发零售业务，谢镕仁还带领正大集团积极拓展电信电视、金融、地产、机械加工等多元化业务领域，形成了多产业协同发展的格局。
  * **国际合作**：他注重国际合作，与全球多家知名企业建立了战略伙伴关系，共同开拓国际市场。正大集团的产品和服务已覆盖全球多个国家和地区，成为具有国际影响力的大型跨国企业。
