# 李桂雄：泰国潮汕籍商业巨头与侨领

## 人物简介
- **姓名**：李桂雄
- **出生日期**：1963年
- **出生地**：中国汕头潮南区成田镇简朴村[^141^]
- **主要成就**：
    - 泰国环球集团总裁[^140^]
    - 泰国中文电视台董事长[^140^]
    - 泰国华人青年商会永远名誉会长[^142^]
    - 泰国中华总商会副主席[^143^]
    - 泰国中国和平统一促进会副会长兼秘书长[^140^]
    - 中国和平统一促进会理事[^140^]
    - 中华海外联谊会理事[^140^]
    - 中国侨联委员[^140^]
    - 中国广东省政协特聘委员[^140^]

## 早年经历
- **下南洋**：1981年，18岁的李桂雄随父母回到泰国[^142^]。
- **教育背景**：在泰国，李桂雄先后在龙船寺、华南蓬寺、马哈赴他南寺等学校就学[^140^]。
- **家族背景**：李桂雄的外公早年在泰国曼谷唐人街卖鱼，后与朋友合伙创办碾米厂[^142^]。

## 商业成就
### 珠宝行业
- **起步**：20世纪90年代，李桂雄与几位堂兄弟合作创办环球珠宝公司[^142^]。
- **发展**：环球珠宝旗下的“永泰珠宝”和“永恒珠宝”成为珠宝行业的佼佼者[^140^]。
- **业务**：公司从事宝石与饰品贸易，将泰国切割好的蓝、红宝石半成品出口到中国，并在广州、深圳、上海设立分公司[^142^]。

### 多元化经营
- **地产开发**：李桂雄创办泰国环球置业有限公司，从事地产开发[^142^]。
- **资源再利用**：他还创办了泰国环球再循环资源有限公司[^142^]。
- **文具贸易**：李桂雄创立“熊猫牌”，把中国制造的文具、办公用品及体育器材引入泰国，深受当地学生喜爱[^142^]。

### 媒体与文化产业
- **泰国中文电视台**：2005年，李桂雄与中央电视台合作，投资成立了泰国中文电视台并出任董事长[^140^]。
- **文化传播**：电视台致力于报道中国、介绍中国，弘扬中国优秀文化，为泰国人民正确认识中国提供了便利[^140^]。

## 社会活动与贡献
### 侨团工作
- **泰国华人青年商会**：2000年，李桂雄与多位热血青年在泰中建交纪念日这一天，在曼谷创建了亚洲第一个青年华人社团组织——泰国华人青年商会，并出任会长[^141^]。
- **泰中友好**：李桂雄积极参与泰中友好活动，推动两国文化交流与经贸合作[^140^]。

### 慈善与公益
- **捐款**：2015年，李桂雄捐资400万元支持潮南练江整治行动[^141^]。
- **文化交流**：他多次举办中国著名歌唱家来泰演出，丰富泰国华人文化生活[^140^]。

## 家庭与个人
- **家庭**：李桂雄育有二子一女，其中两个儿子在中国接受教育[^142^]。
- **个人品质**：他以谦虚礼貌、宽厚待人著称，深受泰华社区的尊重[^140^]。

李桂雄的故事是泰国潮汕籍华人的成功典范，他不仅在商业上取得了巨大成就，还为中泰两国的文化交流和友好关系做出了重要贡献。
