# 周亮星：情系桑梓的杰出侨领

## 人物简介
- **出生与背景**：周亮星，1915年出生于广东潮南区峡山镇东宅村。
- **早年经历**：15岁赴香港谋生，初为雇员，10年后自创益兴隆粮、油、柴、炭生意，并创元泰隆油米业务及元利隆油、米、柴、炭批发。抗日战争胜利后，再创和隆行油、米、炭批发，续创龙子川菜酒楼、元利隆粮食有限公司、合隆行杂货行、元利隆总行及分行、永信米行批发店、永信碾米厂、龙子茶餐厅有限公司、日昌行贸易公司、日昌私人财务公司、中亚布业贸易公司、元利隆父子有限公司等[^81^]。
- **社会职务**：
    - 香港潮州公学创办人之一，任执行校董[^81^]。
    - 曾任港九潮州公会永远名誉会长[^81^]。
    - 曾任香港潮阳同乡会副监事长[^81^]。
    - 1983年被邀请任汕头市政协委员[^81^]。

## 主要事迹
### 一、支援家乡建设
- **捐资兴学**：1989年以来，周亮星带头捐资及独资支援家乡办教育。他深知教育是家乡发展的基石，因此在教育领域投入了大量的心血和资金，为家乡的学校建设提供了重要的支持[^81^]。
- **基础设施建设**：他还积极参与家乡的基础设施建设，如造桥铺路、兴建自来水工程等，为家乡的经济发展和居民生活提供了便利[^81^]。
- **助力陈弼臣家族捐资建校**：周亮星为陈弼臣家族捐资兴建峡山学校费尽心血。他四处奔走，积极协调各方资源，确保学校的建设顺利进行，为当地的孩子提供了优质的教育资源[^81^]。

### 二、推动文化交流
- **组织访问团**：为了加强旅居港澳的乡亲与家乡的沟通，周亮星四处联络奔波，不辞劳苦，近20年来共组织了20多个港澳地区潮汕访问团到家乡观光访问。通过这些活动，增进了港澳同胞与家乡的联系和感情[^81^]。
- **倡议“香港青少年夏令营”**：周亮星积极倡议和组织“香港青少年夏令营”到潮汕观光、寻根问祖。他不顾年迈，连续三年自任团长，带领香港青少年走遍潮汕各地，大大加强了港澳的潮籍后裔对家乡的观念，促进了两地青少年之间的友谊和文化交流[^81^]。

### 三、热心社会公益
- **积极参与香港公益事业**：周亮星不仅在家乡积极贡献，还热心香港的社会公益事业。他是多个社会团体的创始人或重要成员，如港九潮州公会、潮州公学、周氏宗亲总会、中华总商会、德教总会及德教学校、米业商会等[^81^]。
- **赈灾与慈善**：1962年香港遭受台风袭击，灾情严重，周亮星积极参与赈灾活动，带头捐资捐物，赈济灾民[^81^]。

## 总结
周亮星先生是一位杰出的侨领，他一生致力于推动香港与家乡潮汕地区的教育、公益事业以及文化交流。他的无私奉献和辛勤付出，为两地的和谐发展做出了不可磨灭的贡献。他的善举和义举为家乡人民所称道，他的精神将永远激励着后人。
