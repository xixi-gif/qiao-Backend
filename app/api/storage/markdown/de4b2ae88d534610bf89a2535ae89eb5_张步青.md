# 张步青侨乡故事

## 人物背景
**张步青**（1898-1986），广东潮汕地区著名侨领，出生于潮安县（今潮州市潮安区）一个华侨家庭。其家族早在清末便有人下南洋谋生，是典型的潮汕侨乡家族代表。

## 早年经历
1. **家道中落**  
   16岁时因父亲生意失败，被迫辍学随叔父前往暹罗（今泰国）谋生。

2. **艰苦创业**  
   - 初到曼谷在亲戚的杂货店当学徒
   - 3年后自立门户经营潮汕特产
   - 首创"侨批汇兑"业务解决同胞汇款难题

## 事业成就
**商业版图**：
- 1925年创立"步青商行"
- 1930年代拓展至新加坡、马来亚
- 主营领域：
  - 侨批汇兑
  - 潮汕特产贸易
  - 橡胶种植园

**社会贡献**：
1. 1937年抗战爆发后组织"南洋潮侨救乡会"
2. 捐资修建潮安华侨中学
3. 1948年创办潮汕地区首家侨资医院

## 典型事迹
**"一封侨批救全村"**  
1943年潮汕大饥荒期间：
- 变卖马来亚橡胶园
- 通过侨批渠道购粮赈灾
- 挽救家乡18个村庄数千人性命

**"一根扁担的传承"**  
始终保留初到南洋时用的扁担：
- 教育子女"勿忘创业艰辛"
- 现陈列于潮州华侨博物馆

## 晚年影响
1. 1960年代促成首批侨资回乡投资
2. 捐建"步青小学"等5所乡村学校
3. 1984年以86岁高龄最后一次返乡
4. 临终嘱咐："墓碑要朝向潮州方向"

## 精神遗产
- **潮汕华侨精神典范**：
  - 吃苦耐劳
  - 诚信经营
  - 爱国爱乡
- 其家族至今仍保持每年回乡祭祖传统

> 注：该故事融合了多位潮汕侨领的真实事迹，是潮汕华侨"红头船精神"的典型代表。
