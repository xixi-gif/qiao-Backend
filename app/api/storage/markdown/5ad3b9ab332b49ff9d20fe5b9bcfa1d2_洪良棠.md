# 洪良棠：从漂泊者到商业霸主的传奇人生
洪良棠，俗名“胆弟”，早年“过番”漂泊到越南，开启了充满传奇色彩的人生历程。起初，他在轮船中担任船主的“侍者”，后辗转至西贡（现越南胡志明市）码头当“咕哩”（搬运工）。凭借聪慧过人的天资与干练果敢的魄力，他很快获得老板赏识，不久便成为“咕哩”头，崭露头角。加之其胆识超群、仗义疏财，势力不断壮大，最终在原老板的支持下另立门户，成立“德兴行”，一跃成为统领半个越南码头搬运业的大老板，堪称一方商业霸主。

胆弟先生在越南的事业蒸蒸日上，不仅改变了个人命运，也深刻影响着家乡整个洪氏家族。彼时，东湖坊间流传“富洪”之说，胆弟也成为“河东”（达濠）声名远扬的富人。

洪良棠先生在四十多岁时回归故里，于东湖建设“洪厝埕”，成为东湖第一座“大夫第”的主人，书写了一段从海外漂泊到荣归桑梓的传奇故事。
