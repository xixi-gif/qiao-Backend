# 王捷生
王捷生（1926～1990），又名王大目，揭阳县锡场镇（今属揭东区）潭王广美村人。

1938年，王捷生到泰国随父谋生。1941年，日军侵占泰国，王捷生加入泰共领导下的抗日团体“反日大同盟”，积极张贴和散发抗日宣传资料。1945年4月，王捷生加入“暹罗华侨各界抗日救国联合会”，积极动员华侨捐款支援祖国抗战。

日寇投降后，王捷生回国参加革命斗争；1947年6月参加潭王民兵连，1948年1月加入潮汕人民抗征队梅北独立大队，并加入中国共产党；1948年4月，调任中共潮揭丰边西南区武工队，任区队支委兼政治指导员，后分别担任西南武工区北分区书记兼分区队长，潮揭丰边地方大队长、中国人民解放军闽粤赣边纵队二支七团作战参谋等职。

1949年10月起，王捷生分别担任揭阳县警备司令部参谋长，榕城公安分局长，县食品公司党支部书记兼主任，县畜牧办公室主任及科长，丰顺县铜盘农场党支部书记兼场长，丰顺县林业局党支部书记、第一副局长，丰顺县外贸综合公司副主任，丰顺县外贸局副局长等职。1987年，王捷生离休；1990年病逝。
