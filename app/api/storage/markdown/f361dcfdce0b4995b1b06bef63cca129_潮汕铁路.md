潮汕铁路

__一、序章：汕头开埠与交通困局__

19世纪末，汕头开埠后，对外贸易蓬勃发展，商旅客运与日俱增。然而，汕头至潮州的人员和货物运输几乎全靠船只，每到秋冬季枯水期，船只航行异常艰难，潮汕地区的交通瓶颈亟待突破。

__二、第一章：铁路梦起——张煜南与潮汕铁路的诞生__

__（一）华侨张煜南的实业救国梦__

1851年，张煜南出生于广东梅州市梅县区松口镇。少时因家贫辍学经商，后因经营亏损，只身漂泊南洋谋生。经过十多年的锐意经营，他逐渐成为棉兰地区华侨社会中的首富。怀着对家乡的深厚情感，他积极支持家乡的建设和发展。

1903年，清政府出台政策鼓励民办铁路。张煜南受“实业救国”思想影响，决定回国参与家乡铁路建设。他联合张鸿南等爱国华侨，向香港及南洋华商招集股份，获得华侨同胞热烈支持，筹得资金100万银元。同年12月，潮汕铁路有限公司正式成立，集股200万银元，分作一万股。张煜南、谢荣光二人认股100万元，吴理卿、林立生合认100万元。

__（二）潮汕铁路的筹备与建设__

1903年，张煜南进京不久，受到慈禧太后的接见。他随即向清廷提出在韩江下游修建潮汕铁路的计划和潮汕铁路公司章程，获得了清政府的批准。同年，詹天佑受铁路大臣盛宣怀的推荐，担任潮汕铁路的总工程师，负责工程设计和勘测。他经过详细勘察，设计出沿韩江建路的方案，估价在170\-190万元之间。

然而，工程因资金不足需再次增资。日本三五公司趁机介入，通过日籍台湾人林丽生入股，攫取铁路公司总经理之职，并夺取工程建筑承建权。最终，铁路采用日本三五公司的设计方案，从潮州的西面南下，总造价302万元。张氏兄弟各出资100万元，梅县华侨谢梦池认25万元，客居台湾的厦门人林丽生认50万元，另一位投资人张宗煌认20万元，不足之数由张氏兄弟包下。

1904年8月，潮汕铁路完成勘测定线，9月正式动工兴建。这条铁路采用标准尺寸铁轨，机车、枕木和铁轨从美国进口，客车和车厢以及其他材料则来自日本。

__三、第二章：通车盛况——潮汕铁路的运营与繁荣__

__（一）正式通车与运营__

1906年10月，潮汕铁路自汕头筑至潮州城，11月25日正式通车。1908年，铁路延伸至意溪对岸，全线完成，总长42\.1公里。铁路南起汕头，北至潮安，分汕头、庵埠、华美、彩塘、鹳巢、浮洋、枫溪、西门、意溪等站，是一条客、货兼运的干线。

__（二）运输服务与经济繁荣__

潮汕铁路的建成通车，极大地促进了当地物资交流和商旅出行。以前从汕头往返潮州，旅客不得不乘船，逆水要行驶18个小时，顺水也得11个小时。而火车只用1小时18分钟就能走完全程。铁路运送的旅客从1907年的698343人次逐步增加到1910年的805130人次。1910年的总货运量为22\.475吨。

据饶宗颐《潮州志·交通志》记载，潮汕铁路公司初期有机车3辆，头等客车3台（每台定座12人），二等客车3台（每台定座26人），三等客车13台（每台定座50人）；机车购自英国，实为美国制造，其余车辆、材料均从日本购买。铁路开办之初，各站站长、列车长等全用日本人，其后逐渐改用国人。

1931年整顿后，公司有机关车5台，头等客车3台，二等客车3台，三等客车24台，货车抵框车17台，高棚车30台。初时火车每日往返3次，对开后6次。1921年，潮汕铁路日均载客量约4000\-5000人次，日均货运量约100吨，是当时中国营业状况最好的铁路之一。

__四、第三章：挑战与困境——潮汕铁路的艰难岁月__

__（一）路权之争__

20世纪初，清政府风雨飘摇，腐败无能，在铁路路权问题上向外国列强出卖国家利益。四川爆发“保路运动”，掀起了全国民众保路高潮。潮汕铁路虽由华侨集资，但日本通过林丽生入股，企图攫取铁路公司总经理之职，并夺取工程建筑承建权。在日本留学的潮汕籍学生据理力争筑路权，多次电请商部查实。清政府派员与张煜南密商后，命令张煜南负责设法收回林丽生的股份，保住路权。直至宣统元年（1909年）8月，张煜南兄弟才赎回林丽生的股份。

__（二）潮汕铁路案__

1904年9月28日，潮汕铁路正式开工兴建。1905年春，工程筑至庵埠马陇，需穿越人烟稠密的乡村，破坏了农田房屋和坟墓。乡民无法接受，群起反对，驱逐筑路人员。1905年1月21日，潮州葫芦市的农民集众纵火焚毁建筑工地，击杀日本工程人员两人，22日庵埠镇人民罢市示威。

事件发生后，清政府派人调查处理。日本政府乘机向清政府提出无理要求。清政府在日本人的压力下，将农民杨亚会、陈元贞列为杀人和罢市元凶处死，并赔偿日本人命损失费银洋2万6000元。

__（三）抗日战争中的破坏__

1937年，抗日战争全面爆发。为阻止日军侵犯，各地接到破坏交通设施的命令。1939年6月，日军逼近汕头，潮汕铁路被国民政府拆毁。此前，铁路已多次遭到日军飞机轰炸，桥梁及铁路设施多被毁坏。

__五、第四章：余韵流芳——潮汕铁路的文化遗产__

__（一）命名传奇__

潮汕铁路的修建使“潮汕”一词正式诞生。铁路名称中的“潮”（潮州）与“汕”（汕头）首次被联合使用。1907年，孙中山领导的黄冈起义被新加坡《南洋总汇报》称为“潮汕会党”策动，“潮汕”之名首次见诸报端并广泛传播。

__（二）红色交通线__

潮汕铁路是中央红色交通线（南方线粤东段）的重要组成部分，是中央红色交通线中水路与陆路的转接点，为中央苏区运输了大量机密文件、急需物资和经费，为打破国民党的军事“围剿”和经济封锁作出了特殊贡献。

__（三）旧址新生__

潮汕铁路总务处车务处旧址位于汕头火车路18号。2019年，旧址按照“尊重历史、修旧如旧”的原则进行修复。现今所见建筑是参照旧照片复原建造的，尽可能使用原建筑构件和材料。旧址周边空地改造成绿地公园，并布设了潮汕铁路交通历史文化展示墙，成为汕头市区一处独特的历史文化景观。

__六、结语：百年潮汕铁路，见证历史变迁__

潮汕铁路作为中国第一条华侨投资的商办铁路，从1907年开始营业到1939年被拆毁，历时32年。它不仅见证了潮汕地区交通的巨变，也承载着华侨爱国爱乡、实业救国的历史记忆。如今，潮汕铁路虽已不复存在，但它留下的文化遗产和历史记忆，依然激励着后人传承和弘扬先辈们的开拓精神。
