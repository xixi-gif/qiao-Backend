# 杨宗勋

## 一、个人信息

- **姓名**：杨宗勋
- **祖籍**：广东潮安
- **出生地**：柬埔寨

## 二、家庭背景

杨宗勋是柬埔寨柬华理事总会前会长杨启秋勋爵的长子。

## 三、社会职务

1. **柬埔寨王家军三军总司令顾问**
2. **柬埔寨洪森亲王警卫队副司令**
3. **柬华理事总会顾问**
4. **柬埔寨潮州会馆副会长**
5. **柬埔寨王家军总司令部顾问**

## 四、主要成就与荣誉

2023 年 8 月 29 日，柬埔寨国王诺罗敦・西哈莫尼签发《王令》，任命杨宗勋为新任总理洪玛内博士顾问，其职权相当于部长。

## 五、具体事迹

### 1. 政治与军事领域

杨宗勋在任洪森亲王侍卫队总副司令期间，一直为柬埔寨的和平稳定，以及中柬两国的友好关系发挥积极作用。他凭借卓越的领导能力，为保障国家的安全和稳定做出了显著贡献。

### 2. 社团活动与华文教育

杨宗勋担任柬埔寨潮州会馆副会长期间，积极推动华文教育发展，为培养本土华文教师做出了贡献。他还曾出席柬华理事总会师资培训中心第二届师范班毕业典礼，并见证了 71 名学员顺利毕业，这些学员被分配到家乡的华文学校任教，为华文教育的传承和发展注入了新鲜血液。

### 3. 推动中柬友好关系

杨宗勋积极参与中柬友好交流活动，为促进中柬两国在经济、文化等领域的合作发挥了重要作用。他多次接待中国代表团，并陪同柬埔寨领导人访问中国，为深化中柬传统友谊和推动双边关系发展做出了积极贡献。

### 4. 在柬华理事总会的工作

杨宗勋作为柬华理事总会的顾问，积极参与总会的各项工作和活动，为柬埔寨华人社区的发展和团结做出了贡献。他协助总会组织各类活动，推动华人社团的凝聚力和影响力，为维护华人权益发挥了重要作用。

## 六、人物评价

杨宗勋作为柬埔寨华裔将军，在柬埔寨政界和军界具有重要地位。他继承了父亲的遗志，致力于推动柬埔寨华人社区的发展和中柬友好关系的深化。他为柬埔寨的稳定和发展做出了积极贡献，是柬埔寨华人社区的重要领袖之一。
