# 吴文发侨胞故事

## 个人简介
- **姓名**：吴文发
- **籍贯**：广东汕头濠江
- **职务**：新西兰潮属总会常务副会长

## 创业奋斗
- **初到新西兰**：吴文发初到新西兰时，面临诸多困难，包括语言障碍、文化差异以及创业资金不足等。但他凭借坚韧不拔的毅力和潮汕人特有的商业头脑，逐步在新西兰站稳脚跟。
- **事业发展**：经过多年努力，吴文发在新西兰的事业取得了显著成就。他成功创办了多家企业，涉及多个领域，为当地经济发展做出了重要贡献。

## 心系家乡
- **对家乡建设的感慨**：
    - **汕头海湾隧道通车**：2022年汕头海湾隧道正式通车，吴文发作为海外潮人代表，表达了对这一“百年梦想”工程的激动之情。他提到隧道的开通极大便利了潮阳、濠江等地与汕头中心城区的交通，圆了潮人的百年梦想，并对海湾隧道的开通表示深深的祝福，祝愿家乡越来越好[^1^][^3^]。
    - **返乡见证巨变**：
        - 2018年春节返乡时，吴文发被汕头“一湾两岸”的璀璨夜景所吸引，认为夜景不亚于上海、香港，点亮了侨胞回家的路[^6^][^8^]。
        - 他还特别参观了小公园开埠区、东海岸新城等地，对汕头的城市更新和创文成果表示赞叹，并感慨“回家真好！”，呼吁更多海外潮人回乡投资建设[^6^][^7^]。

## 侨团工作
- **积极参与侨团活动**：
    - 吴文发担任新西兰潮属总会常务副会长，积极参与侨团的各项活动，为侨胞们提供帮助和支持。他组织开展了多次侨胞交流活动，增强了侨胞之间的凝聚力[^6^][^8^]。
    - 积极参与国际潮团联谊年会等侨界活动，促进潮商合作[^8^]。

- **维护侨胞权益**：吴文发在侨团工作中，始终把维护侨胞的合法权益放在首位。他积极与新西兰当地政府沟通协调，为侨胞解决实际困难，赢得了侨胞们的广泛赞誉[^6^][^8^]。

## 社会贡献
- **慈善事业**：吴文发热衷于慈善事业，积极参与各类公益活动。他多次为新西兰当地的慈善机构捐款捐物，帮助那些需要帮助的人[^6^][^8^]。
- **文化交流**：吴文发积极推动中新两国的文化交流。他组织了多次中新文化交流活动，增进了两国人民之间的相互了解和友谊[^6^][^8^]。

## 推动潮汕文化海外传播
- **宣传家乡发展**：作为新西兰潮属总会负责人，吴文发积极向海外侨胞宣传汕头的发展，鼓励“侨二代、侨三代”回乡寻根[^6^]。
- **促进潮商合作**：他通过参与国际潮团联谊年会等活动，推动潮汕文化与海外的交流，促进潮商之间的合作[^8^]。

## 与汕头侨乡的联系
- **关注家乡交通建设**：吴文发高度关注家乡的交通建设，认为海湾隧道、海湾大桥等工程是“汕头走向繁荣的桥梁”[^1^][^3^]。
- **城市发展**：他对汕头创文、灯光夜景、东海岸新城的崛起表示自豪，认为这些变化展示了汕头的现代化和国际化[^6^][^8^]。
- **侨务贡献**：通过侨团组织，吴文发搭建了海外潮人与汕头的联系纽带，为家乡的发展和中新两国的友好合作做出了积极贡献[^6^][^8^]。

## 未来展望
- **继续贡献力量**：吴文发表示，他将继续发挥侨胞的桥梁作用，为家乡的发展和中新两国的友好合作做出更大的贡献[^6^]。
- **助力家乡发展**：他相信，在侨胞们的共同努力下，家乡的明天一定会更加美好[^6^]。
