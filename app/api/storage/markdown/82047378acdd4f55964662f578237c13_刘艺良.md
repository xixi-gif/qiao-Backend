刘艺良先生是澳门著名的爱国企业家、侨界领袖，以下是他的详细情况：

# 一、个人背景
- 出生背景：刘艺良先生1957年8月生于广东潮州的一个华侨家庭，祖辈曾远渡海外谋生，父辈又归乡投身祖国建设。
- 早年经历
    - 闯荡澳门：上世纪70年代初，20岁出头的刘艺良只身前往澳门创业。初到澳门，无依无靠的他为了生存，一天打四份工，几乎连休息的时间都没有。后来，由于好学能干，刘艺良被一家房地产物管公司相中。凭着出色的业绩，他从一名普通的物业管理员，一步步晋升为公司总经理。
    - 初入内地：上世纪70年代末80年代初，祖国内地的改革开放为澳门企业家带来巨大机遇。刘艺良抓住机会，在澳门成立了房地产公司及物业管理公司，从房地产买卖、物业管理做起，后来建起了属于自己的大厦，事业由此起步。随着改革开放的深入，他又陆续在广东、北京、河北等省市投资了房地产、物流、灯饰等多个多元行业。

# 二、主要经历
### （一）商业成就
- 白手起家：刘艺良先生从建筑工人、看更人做起，凭借坚韧不拔的毅力和敏锐的商业洞察力，逐步发展起自己的事业。
- 企业集团：他创建的澳门创世企业集团，涵盖房地产、物业管理、科技、基建投资等多个领域，业务遍及澳港台及内地多个省市。
- 业界声誉：2004年，刘艺良先生入选《中国100位地产领袖》排行榜，与李嘉诚等知名地产巨子一同入选，其在地产界的影响力和卓越贡献得到了业界的高度认可。

### （二） 社会职务
- 侨界领袖：刘艺良先生担任中国侨联兼职副主席、澳门归侨总会永远会长、澳门地区中国和平统一促进会会长等职，积极推动侨务工作，凝聚侨心侨力，为侨胞服务。
- 社团领袖：他还是澳门潮州同乡会创会成员、澳门潮属社团总会主席，在推动潮汕文化传承、团结潮籍乡亲等方面发挥了重要作用。
- 其他职务：刘艺良先生担任澳门特区政府经济发展委员会顾问、澳门中华总商会副理事长、澳门地产业总商会常务副会长等职，为澳门的经济建设和社会发展积极建言献策。

### （三）参政议政
- 人大代表：刘艺良先生是第九至第十四届澳区全国人大代表，尽职履责，代表澳门居民参与国家事务管理，积极为澳门和内地的发展建言献策。
- 建议贡献：他提出的“在资金上支持拱北口岸改扩建”“延长通关时间”等建议，得到了国家的高度重视和采纳，为促进澳门与内地的人员往来和经济发展发挥了积极作用。

### （四）公益贡献
- 家乡建设：刘艺良先生始终心系家乡潮州，积极为家乡的建设和发展贡献力量。他捐资襄助牌坊街重建、潮州广济桥修复等项目建设，还捐资支持镇海楼续建工程。
- 慈善公益：他热心慈善事业，向潮州市文化公益基金会、潮州市慈善总会等捐款，支持“广东扶贫济困日”活动，以实际行动回馈社会。

# 三、主要荣誉
- 荣誉博士：刘艺良先生成为澳门大学荣誉博士。
- 全国表彰：他荣获“全国归侨侨眷先进个人”等多项荣誉，这些荣誉是对他在经济、社会、侨务等方面突出贡献的高度认可。

刘艺良先生以其卓越的商业才能和对社会的杰出贡献，成为澳门华人界的杰出代表。他不仅在商业上取得了巨大成功，更为澳门的繁荣稳定、祖国的和平统一大业以及家乡的发展做出了重要贡献，是海外潮商的典范和骄傲。
