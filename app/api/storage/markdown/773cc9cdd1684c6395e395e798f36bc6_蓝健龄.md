# 蓝健龄：情系桑梓的侨领

## 人物简介
- **身份背景**：
    - 泰国澄海同乡会永远名誉理事长[^181^]。
    - 澄海荣誉市民[^181^]。
    - 泰国京华纸业有限公司董事长[^181^]。
    - 泰国潮州会馆名誉主席[^174^]。
    - 泰华文化教育基金会副主席[^174^]。
    - 泰国报德善堂董事[^174^]。

## 主要事迹
### 一、热心公益事业
- **教育事业**：
    - **苏北中学**：1991年，澄海苏北中学按照政府的规划重建校舍，蓝健龄带头捐资60万元人民币，建设了拥有34间教室的教学大楼[^175^]。他还发动旅居泰国的郑碧波家族捐资190万港元，兴建碧波图书馆、礼加礼堂、诒森体育场以及学校大门等建筑[^175^]。
    - **树础学校**：1992年，蓝健龄与陈耀群等66位华侨合共捐资100万元人民币，为树础学校建了教学楼[^175^]。
    - **河美小学**：1994年，蓝健龄与郑若辉、张淑益、郭衍凯伉俪等侨胞捐资172.8万元人民币，为河美小学建设教学楼[^175^]。
    - **南社小学**：1994年，蓝健龄与泰国侨胞蓝锦潮等捐资63.16万元人民币，新加坡侨胞吴锡波、吴卓茂等捐资6.19万元人民币，香港乡亲陈绍华、周如兰捐资8万元人民币，合作为南社小学建设教学楼[^175^]。
- **医疗事业**：
    - 2019年4月6日，蓝健龄先生在80岁华诞之际，偕同家人前往泰京天华慈善医院膜拜观世音菩萨，并拨善款10万铢，捐助天华医院的慈善工作[^174^]。
    - 日前，由他纳昌保险（大众）有限公司代表发展保险部顾问乃披实·旺班率领高级行政人员一行十二人，莅临报德善堂，捐赠21.98万铢，用于慈善事业，该款项由蓝健龄先生接收[^177^]。

### 二、参与侨团活动
- **侨团领导**：
    - 蓝健龄在泰国澄海同乡会中担任重要职务，为侨团的会务发展做出了积极贡献[^181^]。
    - 他积极参与侨团组织的各项活动，为维护侨胞权益、促进侨胞团结发挥了重要作用[^181^]。
- **文化交流**：
    - 蓝健龄致力于推动中泰文化交流，为增进两国人民的相互了解和友谊做出了贡献[^174^]。
    - 他通过参与侨团活动，积极弘扬中华文化，促进侨胞对祖籍国文化的传承和发展[^174^]。

### 三、其他贡献
- **樟林古港**：2000年春，在蓝健龄等旅泰侨领的倡议下，旅泰侨胞踊跃捐资购买樟树种苗，并组团回乡亲植樟树，美化绿化故土[^184^]。
- **隆都中学**：在捐款重建隆都中学的人群中，蓝健龄与旅泰澄海同乡会副会长朱岳秋等侨胞积极发动他人加入捐资的行列，为学校的重建工作做出了重要贡献[^176^]。

## 总结
蓝健龄先生是一位杰出的侨领，他一生致力于推动家乡的教育、医疗和公益事业以及侨团活动。他的无私奉献和辛勤付出，为家乡的和谐发展做出了不可磨灭的贡献。他的善举和义举为家乡人民所称道，他的精神将永远激励着后人。
