# 吴南生侨乡故事

## 人物背景

**吴南生**（1922-2018）：
- 籍贯：广东潮阳
- 身份：革命家、改革开放先驱
- 特殊贡献：深圳特区早期主要规划者
- 侨乡情结：毕生心系潮汕侨乡建设

## 革命岁月中的侨乡情

1. **抗日救亡时期**（1937-1945）
   - 组织潮汕青年抗日同盟
   - 动员华侨捐款支援前线
   - 建立地下交通线（汕头-香港-东南亚）

2. **解放战争时期**（1946-1949）
   - 创办《团结报》（后改版为《汕头日报》）
   - 策划侨乡土改试点
   - 保护侨胞祖宅免遭破坏

## 改革开放的侨力引擎

**1979-1985年主政汕头期间**：
- **三大创举**：
  1. 首创"侨房发还"政策
     - 清退被占侨产房屋1200余栋
     - 修复陈慈黉故居等侨宅
  2. 建立汕头经济特区
     - 借鉴新加坡裕廊工业区模式
     - 设立全国首个侨资开发区
  3. 举办国际潮团联谊年会（1981）
     - 开创"以侨引侨"新模式

- **经典案例**：
  - 说服泰国正大集团谢国民投资汕头
  - 促成香港李嘉诚捐建汕头大学
  - 修复潮州湘子桥（华侨集资）

## 晚年侨务工作

**1990年代后**：
- 主编《广东华侨史》
- 推动"潮汕文化海外行"
- 建立侨批文物馆
- 促成侨乡古村落保护立法

## 精神遗产

1. **侨务理念**：
   - "侨胞是改革开放的天然桥梁"
   - "保护侨乡文化就是守护华侨根脉"

2. **民间记忆**：
   - "骑着单车访侨户"的作风
   - "一杯工夫茶谈成大项目"的佳话

> 注：吴南生故事集中体现"侨乡干部"的典型形象，其将华侨资源转化为发展动能的实践，成为新时代侨务工作的宝贵经验。
