# 姚勇、姚宾兄弟：中老友谊的践行者与商业传奇

## 人物简介
- **姚勇**：老挝中华总商会副会长[^125^]，山西省侨联海外顾问[^128^]。
- **姚宾**：老挝中华总商会会长[^128^]，被老挝前国家主席朱马里誉为“最信任的中国女婿”[^126^]。
- **祖籍**：广东潮阳[^131^]。

## 早年经历
- **出国创业**：20世纪80年代末，姚宾加入出国淘金潮，最初在泰国跟随亲戚从事外贸生意[^129^]。
- **初到老挝**：1989年，姚宾随老板前往老挝谈生意，发现老挝市场潜力巨大，决定在此发展[^129^]。

## 商业帝国的构建
### 贸易起步
- **早期贸易**：1990年，姚宾从中国进口自行车和瓷砖到老挝销售，赚取了人生的第一桶金[^127^]。
- **贸易扩张**：随后，姚宾的贸易公司不断扩大规模，垄断了老挝的部分市场[^127^]。

### 建筑与房地产
- **建筑领域**：1994年，姚宾进入老挝建筑工程领域，帮助老挝政府与中资公司合作[^131^]。
- **危机中的机遇**：1997年亚洲金融危机期间，姚宾利用手中的美元抄底老挝的土地和房产，完成了向房地产建筑行业的转型[^131^]。
- **代表项目**：
    - **万象新世界**：与多家大型国际企业合作开发的房地产项目[^125^]。
    - **亚欧峰会首脑别墅**：为2011年第九届亚欧首脑会议专门建设的豪华别墅[^131^]。
    - **万象中心**：位于万象市中心的黄金地段地产项目[^125^]。

### 酒店与旅游
- **湄公河畔地标酒店**：2012年，姚宾投资建设的湄公河畔地标酒店，成为老挝当地的标志性建筑[^132^]。
- **琅勃拉邦高尔夫球俱乐部**：收购并运营老挝最大的高尔夫球场[^125^]。

## 对中老友谊的贡献
- **民间大使**：姚勇和姚宾被老挝副总理宋沙瓦阁下誉为“中老两国的民间大使，传播友谊的使者”[^127^]。
- **牵线搭桥**：兄弟俩为中老两国的众多合作项目穿针引线，如东盟运动会主体育场、万象瓦岱国际机场等[^131^]。
- **慈善事业**：姚宾赞助了万象市政府大楼、广州亚运会老挝体育代表团、老挝乒乓球队，并为老挝孤儿院、老人院捐款捐物[^127^]。

## 家族与社会影响
- **家族企业**：2005年，姚勇和姚宾创办的老挝吉达蓬集团公司成立，成长为老挝国内最具综合实力的企业之一[^125^]。
- **社会职务**：姚宾还担任老中友协成员、老挝万象中华理事会副理事长、老挝中国总商会名誉会长等职务[^129^]。
- **华人认可**：姚氏兄弟在华人圈和老挝政商各界享有极高的声誉，被认为是“老挝最慷慨、最热衷慈善事业的富人”[^127^]。

## 与家乡的联系
- **侨博会**：2013年，姚勇和姚宾回到家乡汕头参加第五届粤东侨博会，并被聘为汕头市海外交流协会名誉会长[^125^]。
- **投资家乡**：兄弟俩表示，希望未来能回到祖国、回到家乡投资，为家乡的建设添砖加瓦[^125^]。

姚勇、姚宾兄弟的故事，不仅是一部商业传奇，更是中老友谊的生动写照。他们在老挝的奋斗历程，展现了潮汕人的拼搏精神和爱国情怀。
