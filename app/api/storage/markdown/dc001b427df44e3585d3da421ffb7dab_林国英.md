__林国英：坐言起行，革命实行家__

在近代中国的历史长河中，有这样一位杰出的旅日华侨，他以坚定不移的革命信念和无畏的行动，为祖国的独立与解放贡献了毕生的力量，他就是林国英先生。

__早年求学，结缘革命__

林国英，字伟侯，出生于越南西贡的一个华侨家庭。自幼聪慧好学的他，在家乡接受传统教育后，于1895年远赴日本留学。在日本，林国英不仅接受了先进的思想洗礼，还在1906年加入了孙中山先生创立的同盟会，从此踏上了革命的道路。

__丁未黄冈起义，勇挑重担__

1907年，孙中山先生决定在广东西部和东部同时发动起义，黄冈因其地理优势被选为潮州起义地点。林国英受孙中山委任为革命后方指挥官，负责策划和组织起义。他积极募捐，解决起义经费问题，为起义的顺利进行付出了巨大努力。尽管起义最终失败，但林国英的勇敢和担当为他赢得了“坐言起行，革命实行家”的美誉。

__心系家乡，赈灾济困__

1943年，林国英的家乡隆都遭遇严重旱灾，田园龟裂，水源枯竭。得知情况后，林国英立刻前往安南（今越南）发动华侨募捐，并将自家谷仓的粮食出售，筹集款项回乡赈济难民。他还在家乡流行霍乱病时，从广州配制特效药免费施赠乡亲，这些善举成为隆都镇流传的佳话。

__抗日救亡，坚守信仰__

抗日战争爆发后，汕头被日军侵占，林国英携家人回乡避难。他坚决反对日货，在隆都店市开办合作社，专售中国货，以实际行动支持抗日救亡运动。他始终坚守自己的信仰，为民族解放事业贡献着自己的力量。

__名人故居，历史见证__

林国英的故居位于隆都镇鹊巷村荣庆里，是一座民国初年建筑的二层洋楼。孙中山先生曾数次到汕头，亲临荣庆里寻访林国英，并在“怡园书斋”驻跸两夜，与他商讨国事。这座故居见证了林国英先生为革命奔走的历史，也承载着他对祖国的无限忠诚。

林国英先生的一生，是为革命事业和家乡建设不懈奋斗的一生。他身在异国，心向祖国，对革命忠诚，信念坚定。作为一名旅居国外的爱国华侨，他在我国民族革命和民主革命时期，特别是在辛亥革命、抗日战争中投入了巨大的热情，积极投身于祖国和家乡的各项事业建设，为后人树立了光辉的榜样。他的事迹，将永远铭刻在历史的丰碑上，激励着一代又一代的中华儿女。
