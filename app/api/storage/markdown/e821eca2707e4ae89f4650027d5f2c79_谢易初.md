# 谢易初侨领故事

## 人物概览
**谢易初**（1896-1983）：
- 原名谢进强，广东澄海人
- 著名爱国侨领、实业家
- 正大集团创始人
- "中国华侨实业救国先驱"称号获得者

## 南洋创业史

### 白手起家（1922-1936）
1. 1922年赴暹罗（泰国）谋生
   - 随身携带：一袋菜籽、一把秤
   - 初始职业：菜籽小贩
2. 1924年创办"正大庄"菜籽行
   - 首创"货真价实、童叟无欺"经营理念
   - 开发改良暹罗本地菜种

### 事业扩张（1937-1949）
- 建立东南亚最大种籽公司
- 发明"易初牌"优良种籽
- 二战期间坚持平价供应民生物资

## 报效桑梓

### 经济建设
- 1950年投资创办汕头罐头厂
- 1961年捐赠澄海首座化肥厂
- 1979年助推汕头经济特区设立

### 文教贡献
1. 捐建澄海华侨中学
2. 设立"易初奖学金"
3. 修复澄海文庙

## 家国情怀
- **"三心"家训**：
  - 对祖国要忠心
  - 对事业要专心
  - 对同胞要爱心
- 临终遗言："把骨灰一半撒在韩江，一半留在曼谷"

## 历史定位
> "谢老一生诠释了华侨精神的三个维度：在异域闯出一片天，为祖国倾尽一份力，给家乡留下一座碑。"（《潮汕华侨志》评述）

## 纪念传承
- 汕头"易初纪念馆"
- 泰国华侨崇圣大学谢易初铜像
- 澄海"易初大道"
