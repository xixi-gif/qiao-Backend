# 陈有汉：泰国金融巨擘的传奇人生

## 一、个人背景
陈有汉，1934年2月28日出生于泰国曼谷，祖籍广东潮阳峡山（今汕头市潮南区），是泰国著名侨领、盘谷银行创办者陈弼臣的次子。他幼时曾回乡就读于汕头市聿怀中学，1953年毕业于香港广大高级会计学院，后赴英国伦敦雷伦专科学院攻读银行学，1957年毕业后在英格兰皇家银行实习。

## 二、主要经历
### （一）早年经历
1. **英国求学**：1957年，陈有汉在伦敦雷伦专科学院毕业后，到英格兰皇家银行实习。实习期间，他对欧美经济制度和国际金融知识有了深入研究，并逐步掌握了现代金融管理技能。
2. **初入职场**：1958年，陈有汉回到泰国，先在曼谷亚洲信托有限公司实习6个月，凭借出色的表现很快被提升为副经理。1959年10月，他进入盘谷银行工作，从会计部副经理做起。

### （二）盘谷银行的接班与管理
1. **晋升之路**
     - 1959年，陈有汉加入盘谷银行，凭借其专业背景和父亲的悉心指导，三年后升任会计部经理，并获得代表银行签字的资格。
     - 陈有汉在会计部任职十几年间，兢兢业业，从早到晚处理业务，直至最后一份支票核准、现金入库后才回家。但父亲陈弼臣并未立即让他接班，而是注重接班人的能力和品性。
     - 1980年3月，陈有汉凭借自身实力，经董事局一致推举，出任盘谷银行总裁。在其领导下，盘谷银行进入新的辉煌时代，发展速度和业绩均超过以往任何时期。

2. **管理理念与创新**
     - 陈有汉采取“中西结合”的管理方式，将现代金融理论与父亲的经营理念相结合。他强调团体精神，推动盘谷银行从家族企业向团队协作转变，认为员工是银行的最大资产，注重调动员工积极性。
     - 他总结出“微笑质量”理念，即服务、管理、公关形象、信贷和员工素质五个要素（SMILE），以此提升银行服务质量。同时，陈有汉在信息技术应用方面具有远见，早在20世纪70年代就推动盘谷银行引入计算机技术，并在泰国首家实现存款计算机联网，后又实现全球分行联网，使盘谷银行成为世界先进的“电子银行”。

3. **业务拓展**
     - 陈有汉继承并改进了父亲的经营管理策略，继续“任人唯贤”，吸引大批现代管理人才。他还秉承父策，积极开拓海外市场，将盘谷银行业务从香港扩展到日本、新加坡、伦敦、马来西亚等地，抢占竞争先机，使盘谷银行成为东南亚最大的私人商业银行和泰国金融支柱之一。

### （三）社会职务与荣誉
陈有汉曾任泰国银行公会主席、泰中友好协会副主席、亚洲水泥有限公司董事长、泰美商业促进委员会主席、亚洲太平洋银行家俱乐部主席等职务。他三度被评为“泰国杰出银行家”，被美国《财富》杂志评选为“1990年亚洲25位杰出银行家之一”，获亚太银行家协会颁授“卓越银行家最高荣誉奖”，并分别获得美国加州碧拍莱大学财政学名誉博士学位和菲律宾德拉赛尔大学企业管理名誉博士学位。

## 三、社会贡献
1. **热心公益**：陈有汉继任父业后，注重树立盘谷银行良好形象，每年捐出巨款用于社会救济、学校奖金，并在全国城乡兴建福利设施，为泰国的保健、教育、文化等事业做出重要贡献。
2. **支持家乡教育**：陈有汉幼时曾回汕头聿怀中学就读，成名后不忘家乡母校，捐资兴建了有汉教学楼、陈有汉先生科学馆及有汉先生大礼堂等设施，还捐资在潮南建设图书馆、体育馆等，推动家乡教育事业的发展。

陈有汉博士以其卓越的金融才能和对社会的杰出贡献，成为泰国华人界的杰出代表。他不仅领导盘谷银行走向辉煌，还在中泰两国的经济、文化等领域发挥了重要作用，是海外潮商的典范。
