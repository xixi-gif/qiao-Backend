__许敦茂：促进泰中交流的友好使者__

许敦茂祖籍后沟村，其父许得胜是泰国挽卡纳村首任村长。他 7 岁时被送往隆都家乡读中文，后回泰国继续学业，毕业后成为教师并升任校长。许敦茂还到中国就读海外师资特别训练班，毕业后归泰，成为泰国首位在中国师资毕业的华裔大学生，并进入泰国曼谷法政大学攻读法律。心怀祖国的他，1972 年率泰国乒乓球队参加北京第一届亚洲乒乓球锦标赛，同年率泰国贸易代表团到广州参加秋季中国进出口商品交易会，力主恢复泰中贸易往来。许敦茂多次访华，受到周恩来、邓小平接见，也曾回家乡探亲。
