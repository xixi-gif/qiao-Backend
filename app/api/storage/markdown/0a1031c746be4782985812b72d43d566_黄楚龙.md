# 黄楚龙：从泥瓦匠到千亿身家的深圳地产大亨

## 一、个人背景
1. **出生背景**
   - 1959年，黄楚龙出生于广东省普宁市东埔村的一个贫苦家庭，家中兄弟姐妹6人。
2. **早年经历**
   - 为了缓解家中的经济压力，黄楚龙辍学养家糊口，19岁只身前往深圳闯荡。起初靠做泥瓦匠维持生计，后凭借敏锐的观察力和努力，成为包工头，赚到了人生中的第一桶金。

## 二、主要经历
1. **创业初期**
   - 1979年，到深圳创业。
   - 1988年12月，创立星河地产的前身深圳市怡和企业公司。
2. **进军房地产**
   - 1994年4月，成立深圳市新怡和实业发展有限公司，先后开发了祥和花园、怡和楼等多个项目。
   - 1998年，开发星河明居，星河系列化产品开始萌芽。
   - 1999年12月，将公司更名为深圳市星河房地产开发有限公司，开发星河雅居。
3. **商业拓展**
   - 2002年，开发的星河·国际在深圳市规划与国土资源局年度综合企业排名中名列第14位。
   - 2003年，斥资1.8亿元人民币竞得中心区第一块招标拍卖五星级酒店用地，随后又购得购物公园、岗厦项目。
   - 2009年，参股阳光保险。
   - 2010年至2011年，先后两次入股深圳市创新投资集团有限公司，成为第二大股东。
4. **金融布局**
   - 黄楚龙还涉足金融领域，成为深圳创新投资集团、深圳福田银座村镇银行的重要股东，还是前海母基金、国家中小企业发展基金的有限合伙人。

## 三、商业成就
1. **星河控股集团**
   - 黄楚龙一手创办的星河控股集团是国内大型综合性投资集团，旗下涉及地产、金融、置业、产业四大集团。公司未上市，黄楚龙被称为深圳的“隐形富豪”。
   - 2024年，黄楚龙以490亿元人民币财富位列《2024胡润全球富豪榜》第437位。
2. **房地产领域**
   - 星河地产在行业内树立了良好的口碑与品牌形象，连续11年入选中国地产百强。黄楚龙坚持“零延期，零差距，零等待，零担忧，零顾虑，零距离”的六零标准。
3. **金融投资**
   - 星河资本管理规模超300亿，自有资金超百亿，累计投资超200家企业，包括至少26家上市公司，如迈瑞医疗、蓝思科技等。

## 四、社会贡献
1. **热心公益**
   - 2003年，黄楚龙捐出千万豪宅给深圳红十字会，用于慈善事业。
2. **社会职务**
   - 黄楚龙担任深圳市普宁商会会长，积极为潮汕商人发声，推动潮汕商会的发展。

黄楚龙从一名泥瓦匠到如今的千亿身家，他的成功并非偶然，而是源于其敏锐的商业嗅觉、稳健的经营策略以及对社会的回馈。他的商业传奇和人生哲学，为地产界乃至整个商业领域树立了标杆。

## 五、家庭情况
黄楚龙有两子一女，子女们都有在国外学习和工作的经历。长子黄德安在星河控股担任常务副总裁，协助整体运营管理；次子黄德林负责商业运营服务。
