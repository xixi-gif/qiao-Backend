# 刘思仁：潮汕华侨的传奇一生

## 一、早年经历
- **出生与家庭**：刘思仁，1929年出生于广东潮阳，祖籍潮阳深溪乡。
- **初到香港**：18岁时，刘思仁离开家乡，前往香港打工谋生。当时的香港是“潮州人”的天下，他在这里开始了艰难的奋斗历程。

## 二、事业起步与成长
### （一）加入澳娱公司
- 经过二十年的摸爬滚打，刘思仁凭借自己的努力和才华，成为“澳娱公司”总经理的特别助理，也就是赌王何鸿燊的助理。这一时期，他积累了丰富的商业经验和人脉资源。

### （二）葡京“帝皇厅”厅主
- 70年代初期，刘思仁已是葡京“帝皇厅”厅主，负责招待东南亚客人，被称为“叠码仔”祖师爷。他凭借出色的管理能力和商业头脑，在澳门博彩业中崭露头角。

## 三、商业帝国的建立
### （一）餐饮行业
- **接手葡京酒楼**：1984年，刘思仁接手何贤家族的“葡京酒楼”，高调进军餐饮行业。
- **经营潮港城**：1986年，他与“潮州城”的郑合辉在伊丽莎白大厦一同经营“潮港城”，高峰时期他名下大约有十多家酒楼。

### （二）电讯行业
- **买入传呼机公司**：1981年，刘思仁买入香港一家传呼机公司“BB电讯”。
- **改名必备通讯**：两年后，其子刘坤铭接手该公司，改名“必备通讯”，成为香港五大传呼机公司之一。周华健、李宗盛曾是其公司的代言人。但随着手机的普及，传呼机公司于2002年倒闭。

## 四、商业成就与社会贡献
### （一）商业成就
- **担任重要职务**：
    - 澳门葡京酒店总经理
    - 澳门旅游娱乐有限公司顾问兼总经理特别助理
    - 澳门潮州同乡会永远会长
    - 国际钧泰（集团）董事长
    - 香港必备通讯公司董事长
    - 辉源发展有限公司董事长
    - 华泰置业有限公司董事长
    - 香港潮州公会永远会长
    - 香港潮州商会会董
    - 汕头世贸集团副主席
- **投资房地产**：1992年，刘思仁成立汕特汇兴房地产开发有限公司，上世纪90年代初期，该公司在汕头市澄海区投资建设“汇璟花园”。

### （二）社会贡献
- **响应改革开放**：1980年，刘思仁响应祖国改革开放的号召，率先回乡投资、兴办公益事业。
- **累计捐款过亿**：刘思仁、蔡雪芳伉俪热心公益，造福桑梓，为家乡的经济建设和福利事业做出了巨大贡献。在家乡累计捐赠总金额逾港币1.2亿元，其中有8000多港万元用于家乡的教育事业。
- **捐赠项目众多**：
    - 汕头市潮南区峡山医院
    - 潮南区华侨医院
    - 潮南区中医院
    - 潮南区金溪乡小学、中学
    - 潮阳区侨联
    - 澄海区侨联
    - 澄海区西门小学、澄海区幼稚园、小学及中学
    - 澄海区社会治安基金会
    - 汕头市潮汕体育馆
    - 汕头市社会治安基金会
    - 汕头市慈善总会
    - 澄海区慈善总会

## 五、荣誉与地位
- **担任政协委员**：
    - 广东省第七届政协委员
    - 汕头经济特区顾问委员
    - 汕头市政协委员
- **获得荣誉**：
    - 汕头市“荣誉市民”
    - 2009南方华人慈善盛典十大“慈善人物”

刘思仁的故事是奋斗、成功与奉献的完美结合。他不仅在商业上取得了巨大的成就，更在公益事业上做出了不可磨灭的贡献，成为海外华人中的杰出代表。
