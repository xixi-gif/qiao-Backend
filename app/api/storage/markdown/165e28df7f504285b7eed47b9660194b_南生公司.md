南生公司

__一、南生公司的创立__

1928年，梅县籍的印尼华侨李柏桓回到汕头，目睹了汕头市政当局正在拆建安平、国平等马路，意识到这一地带将成为汕头市的交通枢纽和商贸集中地。于是，他联合李耀宗、李远波、李镜泉、李视棠等人，集资50万大洋，成立了南生股份有限公司，简称“南生公司”。公司最初以南生百货商号为基础，后在1932年建成七层高的南生公司大楼，并正式迁入新址营业。

__二、建筑特色与创新__

南生公司大楼的设计独具匠心，原计划为四层，后李柏桓决定扩建成七层，以充分利用空间。为解决地基承载力问题，设计师采取了多种措施：第五层向后退缩，两端各建塔状建筑以均衡压力，各层标高降低以减轻重量。尽管如此，大楼建成后仍出现均匀下沉，但整体结构稳固。

大楼内部安装了汕头第一部电梯，从一楼直达四楼，使用长达60年。此外，大楼还设有“哈哈镜”，成为儿童们的最爱。建筑外立面每层逐次缩小，装饰精美，融合了中西建筑风格，成为汕头市的地标性建筑。

__三、商业繁荣与影响__

南生公司集购物、餐饮、住宿、娱乐于一体。一层和二层经营百货，三层和四层为中央酒楼，五层和六层为中央酒店，七层设有西餐室。大楼的建成吸引了众多资本家在此买地建店，形成了以小公园为中心的繁华商业区。当时汕头埠“四大百货公司”——南生、振源、平平、广发均聚集于此，南生公司更是成为汕头的商业龙头。

南生公司不仅推动了当地商业的繁荣，成为汕头埠的黄金商业旺地和时髦商品的购物天堂，也成为了外来购物者和海外华侨的必访之地。

__四、流传的趣闻轶事__

- __“我父无钱伊阿父有”__：李柏桓的一个儿子曾在南生公司外被人力车工人围住，以高价车费乘车回家。而李柏桓本人却不坐车，步行回家，当被车夫抱怨时，他幽默回应：“我父无钱伊阿父有”。
- __汽水当洗脚水__：一位富家子弟为炫耀财富，购买大量汽水倒在脸盆中当洗脚水，这一行为虽显得浪费，但也反映了当时社会的某些现象。

__五、历史变迁与传承__

1956年，南生公司与汕头市国营百货商场合营，更名为汕头百货大楼，继续在汕头商业领域发挥重要作用。尽管随着时间推移，汕头商业中心逐渐东移，南生公司的辉煌不复往昔，但它作为汕头商业发展的重要标志，依然在人们心中占据重要地位。

如今，南生公司大楼的未来仍存在不确定性，是保留修缮还是拆除重建引发各界讨论。然而，其作为汕头埠发展里程碑的历史地位和深厚人文积淀，值得被铭记与传承。
