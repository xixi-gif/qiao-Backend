# 连瀛洲：从潮汕少年到新加坡金融巨擘

## 一、个人背景
1. **出生背景**
     - 连瀛洲于1906年8月2日出生在广东潮阳（今潮南区）一个书香家庭，祖父是村中长老，父亲是一个布商，母亲出自名门，作为家中长子，连瀛洲被寄予厚望，五岁那年就开始学习毛笔字。
     - 他童年在家乡接受私塾教育，表现出不凡的天赋。然而10岁时，父母相继去世，他小小年纪就面对人生残酷的考验。

2. **早年经历**
     - **赴港打工**：12岁时，连瀛洲在表兄的帮助下被介绍到表兄岳父的店里做工，他跟着村里几个大人，乘上汽船直奔香港，在这家小店里做学徒，老板负责吃住但不发工钱，条件虽然苛刻，小瀛洲却十分勤快，不仅总是手脚不停地忙碌，而且学会了一口流利的粤语。
     - **初到新加坡**：1919年，刚满14岁的连瀛洲，乘小轮船离开香港，到新加坡开始他人生新的转机。他到一家船务杂货店工作，由于工作勤奋，吃苦耐劳，刻苦学习船务供应的一切知识，得到老板的赏识和器重，受到提拔和重用。不到五年，连瀛洲从一名小工升为助理经理。这为他日后创业积累了厚实的经验。

## 二、主要经历
1. **创业历程**
     - **初次创业**：1927年，连瀛洲开始独力创业，成立了自己的船务杂货店。1928年，他22岁时，用自己省吃俭用积攒下来的数万元与朋友合作，创办寓“中华兴旺”之意的华兴有限公司，经营进出口贸易兼代理船务，供应粮食给来往船只。当时马来西亚英国殖民地三军的日常所需粮食，均由华兴公司供应。
     - **二次创业**：1941年，连瀛洲回中国，1944年在重庆创立华侨联合银行，任董事长。战后，连瀛洲回到新加坡并创立了华联银行。华联银行于1946年成立，它是连瀛洲与马来西亚华商发起联合创办的，这个银行直到1949年才正式开业。1986年，华联银行集团建成华联银行中心大厦，楼高280米，当时成为美国以外的最高建筑物，集团属下的华联企业公司所兴建的文华大酒店，也被誉为“世界最堂皇雄伟的旅馆”之一。

2. **商业成就**
     - **华联银行**：连瀛洲是新加坡华联银行的创始人，该银行后与大华银行合并。他通过自己控制的华兴有限公司持有华联银行24.19%股权，这批股票的价值为3.6亿新元（相当于2.1亿美元），成为令人瞩目的亿万富翁。
     - **多元化发展**：连瀛洲的开拓进取，使华联银行集团的业务范围扩大到金融、房地产、投资控股、报业和贸易等，成为新加坡主要的跨国集团之一。连瀛洲执掌的新加坡华联银行集团成为新加坡四大银行之一，他也因而成为新加坡的金融巨擘。华联银行集团除华联银行之外，还控制4家主要的大马上市公司，它们分别是联华企业公司、华联信托公司、华联证券公司及丽嘉酒店。连同子公司在内，这个集团控制的公司多达60多家。

## 三、社会贡献
1. **推动华文教育**：连瀛洲一直致力于推动华文教育的发展，他积极参与和支持华文学校建设，为新加坡的华文教育事业做出了重要贡献。
2. **慈善公益**：连瀛洲积极参与慈善活动，多次为新加坡及中国的灾区人民捐款，是一位慷慨的慈善家。他通过自己的努力，为社会的公益事业贡献了自己的力量。
3. **文化交流**：连瀛洲积极推动中新两国的文化交流与合作，为两国在经济、文化、教育等领域的合作牵线搭桥，增进了中新两国人民之间的相互了解和友谊。

连瀛洲的一生，是为商业发展和社会进步不懈奋斗的一生。他以传承民族精神、弘扬中华文化为己任，为新加坡华人华社事业的复兴和发展作出了历史性贡献。他毕生对发展华人华社事业、促进中新友好作出了不可磨灭的功勋，其贡献得到了中新两国政府和华社的高度评价和赞誉。2004年8月6日，连瀛洲在新加坡逝世，享年98岁。
