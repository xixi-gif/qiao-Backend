__许子奇：学贯中西的革命战士__

许子奇，后沟村人，其父许秋帆为满清秀才，学识丰富。1925 年“五卅惨案”发生时，许子奇正在上海惠灵英文专修学校肄业，他积极参与反帝反封建军阀的斗争。1926 年回到后沟村后，投身乡村教育和农运工作。1927 年春，在后沟学校校长詹天锡的介绍下，许子奇加入中国共产党。1928 年，他前往泰国避难，1930 年回国后，在凤凰镇创办岭东小学，培育当地华侨子弟。1934 年，许子奇进入北平中国大学哲学系，从事潮州话拉丁化研究，并参加“一二・九”示威游行，成为中华民族抗日先锋队的队员。1936 年，他回到家乡养病，任教于潮阳六都中学。1937 年，许子奇前往泰国，在新民学校任教，鼓动学生参与抗日运动。1939 年，他担任“泰国华侨各界抗日救国联合会”党团常委，兼任泰国《中原报》编辑及潮州会馆秘书等职。1941 年太平洋战争爆发后，许子奇响应组织号召回归祖国。日本投降后，他与同志集资开创公司，事业鼎盛。许子奇逝世前参与筹办汕头大学，还被选为中华全国世界语协会理事。
