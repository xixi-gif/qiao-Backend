### 一、杨祁敬的个人经历

1. 杨祁敬，字慎庵，1901年出生，1979年去世，是潮汕著名侨胞杨仁梅的长子，幼时便展现出聪慧与刚毅的性格。
2. 1930年毕业于北平朝阳大学法科，也就是如今的北京大学。毕业后，他曾在汕头和揭阳担任律师，因其卓越的才能，在潮汕地区声名远扬。
3. 后来，杨祁敬回到马来西亚麻坡，继承了父亲杨仁梅的事业。尽管在日军侵占马来亚期间，事业发展受阻，但二战结束后，他凭借敏锐的商业头脑，成功把握商机，扩展了橡胶种植业务，并涉足米业和运输业，使得家族产业迅速崛起，自己也跃居麻坡实业界的翘楚，享誉东南亚。

### 二、杨祁敬的品德与成就

.1 **高尚的个人品德**：杨祁敬自幼深受家族文化熏陶，继承了父亲的美德。他为人诚恳笃实、沉默寡言，生活朴素且性格温谦，乐善好施，积极奖励和扶持后辈，对教育和公益事业更是满怀热忱。
2. **卓越的事业成就**：
    - 在麻坡定居的40年间，杨祁敬在社会上享有极高的声望，曾担任麻坡潮州会馆主席以及多个学校社团的重要职务，深受社会各界的推崇与尊敬。
    - 他尤为重视教育事业的发展，曾担任麻坡中化中学、培华中学、建国学校等知名学校的副董事长。从这些学校的命名中，可以看出杨祁敬致力于弘扬中国文化、培养热爱中华文化的栋梁之才，为祖国的繁荣富强贡献力量。
    - 此外，杨祁敬还在武吉甘蜜坡建立了拥有100多幢房屋的“杨仁梅新村”，作为社会福利项目，以低廉的价格出租给贫困家庭，极大地促进了武吉埠地区的繁荣发展。

### 三、杨祁敬家族的影响

1. **家族教育的重视**：杨祁敬家族极为重视子孙后代的教育。早在民国初年，杨家便在家乡创办了私塾，并聘请优秀的教师执教，坚持男女平等的教育理念，让家族中的女孩也能像男孩一样接受良好的教育。
2. **家族人才辈出**：在良好家风的滋养下，杨祁敬家族人才济济，五代传承，英才辈出。家族成员在国家和民族危难时刻，有的选择投身革命，如1947年杨祁敬的第五个女儿杨琼珍、长孙杨永谋（杨伟）以及侄女杨玉娇等毅然放弃安逸生活，投身革命事业；有的则在教育、科研、医疗、商业等不同领域发光发热，为社会做出了巨大贡献。其中，为中国石油事业立下汗马功劳的原河南省南阳市政协副主席杨祈恕、中山大学博士生导师杨岫岩、美国伍兹霍尔海洋研究所所长杨嘉岩、贵州省干部大学教授杨祈昌等9位杰出代表，更是被收录于《槎桥族谱》的贤哲人物篇章中，成为家族的荣耀与社会的宝贵财富。
