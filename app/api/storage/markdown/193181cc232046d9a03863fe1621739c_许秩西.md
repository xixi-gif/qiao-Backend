# 许秩西：潮汕大地的革命火种

## 人物简介
- **基本信息**：
    - **姓名**：许秩西
    - **出生日期**：未明确提及
    - **逝世日期**：未明确提及
    - **籍贯**：广东省汕头市澄海区隆都镇后沟村
- **身份与地位**：许秩西是潮汕地区早期共产党员之一，也是后沟村的红侨代表[^123^]。

## 革命活动与贡献
### 一、早期革命活动
- **加入共产党**：1926年，许秩西加入中国共产党，随后在后沟村组织农会，参加全县武装起义[^121^][^123^]。
- **建立兵工厂**：他秘密在后沟村的丽泽斋建立小型兵工厂，制造土炸炮，并担任地下交通员[^121^][^123^]。
- **被捕与流亡**：由于身份暴露，许秩西被国民党悬赏抓捕，不得不与妻子孙庆生等同志转移到泰国避险[^121^]。

### 二、在泰国的革命活动
- **领导印刷工会**：在曼谷，许秩西负责印刷工会的领导工作，参加反帝大同盟[^121^]。
- **被捕与坚持斗争**：1929年12月，因叛徒出卖，许秩西在泰国被捕，但在狱中仍坚持斗争[^121^]。
- **出狱与回国**：1938年，许秩西遇泰国国王大赦出狱后，回到家乡继续投身抗日救亡运动[^121^]。

### 三、抗日救亡运动
- **建立革命组织**：回到家乡后，许秩西先后在后沟小学、隆都中学等地建立了共产党领导下的“青抗会”“战时服务工作队”，并与妻子孙庆生创办“隆都华侨抗日救护训练班”，发展党员[^121^][^123^]。
- **动员华侨**：他积极动员华侨捐建澄海的外砂大桥、莲阳大桥、东里大桥等基础设施，并动员侨胞兴办华侨中学和白沙农场[^121^][^123^]。

### 四、新中国成立后的贡献
- **担任重要职务**：1949年回国后，许秩西先后担任中共澄海县委统战部副部长、澄海县人民政府副县长等职[^121^][^123^]。
- **解决侨眷问题**：任职期间，他积极争取解决侨眷、归侨生活困难，以及落实侨房政策等问题[^121^]。

## 家庭与亲属
- **妻子孙庆生**：许秩西的妻子孙庆生与他同年加入中国共产党，是一对生死与共的革命伉俪。1928年，她随夫流亡到泰国。许秩西被捕入狱后，孙庆生连续五年坚持探监，为同时被捕入狱的同志送食品药品。1934年，她由党组织安排回国学医，毕业后在莲下的程洋岗和铁铺的石坵头开设医局，作为地下交通站，为革命同志提供掩护。1941年，孙庆生因病去世[^121^][^123^]。
- **女儿许秋儿**：许秩西的女儿许秋儿表示，她的父母是在后沟村走上革命道路的[^123^]。

## 总结
许秩西是潮汕地区早期的共产党员之一，他为革命事业作出了重大贡献。他的一生，是为革命不懈奋斗的一生，他的事迹激励着后人继续前行[^121^][^123^]。
