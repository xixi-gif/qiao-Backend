# 黄敏如：旅泰华侨的赤子情怀

## 人物简介
- **姓名**：黄敏如，又名黄添贵
- **身份**：旅居暹罗（泰国旧称）的华侨
- **旧宅**：位于广东汕头澄海区东里镇樟林古新街的“又庐”

## 主要事迹
### 一、热心慈善事业
- **多次回国**：黄敏如在37年间多次回国，积极参与家乡的慈善事业[^149^]。
- **慈善贡献**：
    - 他为家乡的教育、医疗、基础设施建设等方面做出了重要贡献，深受乡亲们的敬重和爱戴[^149^]。
    - 据文史爱好者黄敬得介绍，黄敏如在泰国做生意时，发展之后在樟林当地甚至汕头，他的慈善事业做得很大，救灾救荒累计捐赠金额达数万元[^149^]。

### 二、家乡记忆与影响
- **“又庐”旧宅**：
    - “又庐”是黄敏如的旧宅，位于东里镇樟林古新街，是一座面积大约300平方米的两层建筑[^149^]。
    - 该建筑融合了潮汕传统木雕、灰塑和当时罕见的西洋水泥、玻璃，主体框架采用了传统潮汕民居的单背剑建筑格局[^149^]。
    - “又庐”的闪门保留得非常完整，上面的雕刻非常精美，落款是当时清末民国初期当地的书画名家蔡心侬的作品[^149^]。
- **家乡俚语**：
    - 樟林一带曾流行一句俚语“痒去又庐鑢”（大意是“痒的话就到又庐的外墙去蹭一蹭”），这反映了“又庐”外墙的粗糙特性[^149^]。
    - 据说，黄敏如的母亲为了保护房子美观，故意把墙壁弄粗，以防止过往民众随手在墙上蹭痒[^149^]。

### 三、个人经历
- **在泰国的事业**：
    - 黄敏如在泰国开公司，代理美国屈臣氏汽水，还拥有七家戏院和水火灾保险公司[^149^]。
    - 他是家中长子，有五个兄弟，一生娶了三房太太，生了两个女儿，一个在泰国，一个留在老家[^149^]。
- **建设“又庐”**：
    - 1936年，黄敏如从泰国回来建设“又庐”，并将建好的房子分给兄弟姐妹们居住[^149^]。
    - 当时请了两班工人加班加点，刚好100天完工[^149^]。
- **英年早逝**：
    - 黄敏如在56岁时英年早逝，家人只知道他做生意，其他事情都不清楚[^149^]。

## 总结
黄敏如是一位具有深厚爱国情怀和家乡情结的华侨。他在37年间多次回国，积极参与家乡的慈善事业，为家乡的教育、医疗和基础设施建设做出了重要贡献。他的善举和赤子情怀至今仍然受人称道，成为后人学习的榜样[^149^]。
