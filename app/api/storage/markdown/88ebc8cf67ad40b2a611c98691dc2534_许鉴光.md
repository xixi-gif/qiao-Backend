__许鉴光：情系桑梓的米业大王__

许鉴光，乳名镜兴，1921 年生于泰国佛丕府。2 岁时随父母回后沟村居住两年，后返泰谋生。1947 年父亲去世后，他与母亲和弟弟一起发展父亲开创的正明火砻，使其生意兴隆，生产的“金凤唛香米”享誉东南亚、欧美。火砻实现现代化管理后，多次获泰国大米评比第一名，许鉴光受泰皇接见及授予勋章。他事业有成，不忘报效祖国，多次回乡探亲，助力兴办公益事业，如后沟华侨水厂、隆都中学等。1994 年，澄海市人大常委会授予许鉴光“澄海市荣誉市民”称号。
