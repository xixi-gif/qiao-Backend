# 蚁美厚侨领生平

## 人物简介
**蚁美厚**（1909-1994）：
- 原名蚁良润，广东澄海人
- 泰国著名侨领、实业家、慈善家
- 曾任全国侨联副主席
- 被誉为"中泰民间友好使者"

## 奋斗历程

### 早年经历（1909-1927）
1. 1909年生于澄海贫苦农家
2. 14岁随叔父蚁光炎赴泰国谋生
3. 从码头搬运工做起

### 商业成就（1928-1949）
- 创建"泰昌行"贸易公司
- 发展航运业，拥有18艘货轮
- 建立泰国最大大米加工厂
- 二战期间组织侨胞支援抗战

## 家国贡献

### 对祖籍国
1. 1949年应邀参加开国大典
2. 带头投资建设广东华侨大厦
3. 推动汕头经济特区早期建设
4. 捐建澄海人民医院住院楼

### 对侨居地
- 创办泰国中华总商会
- 兴建华侨医院
- 设立泰华孤儿院
- 调解劳资纠纷，促进社会和谐

## 精神遗产

### 家训格言
- "取之社会，用之社会"
- "有国才有家，国强侨方安"
- "做生意要诚信，做人要感恩"

### 荣誉称号
1. 泰国国王御赐"一等皇冠勋章"
2. 中国"侨界楷模"称号
3. 汕头市"荣誉市民"

## 纪念传承
- 澄海"美厚路"
- 泰国华侨报德善堂纪念馆
- 汕头华侨历史博物馆专厅

> "蚁美厚先生用一生诠释了华侨精神的真谛：在异国他乡自强不息，对祖国家乡赤子情深。"（《泰国侨史》评语）
