# 李嘉诚：从潮汕侨乡走出的商业传奇

## 一、潮汕根脉
- **祖籍溯源**  
  1928年生于广东潮州府潮安县（今潮州市湘桥区）
  - 家族属典型潮汕侨乡背景
  - 父亲李云经曾任小学校长

- **战乱迁徙**  
  1939年日军侵华举家避难香港
  - 1943年父亲病逝被迫辍学
  - 在舅父庄静庵（钟表商）的中南钟表公司当学徒

## 二、创业史诗
### 1. 塑胶花起家（1950-1958）
- 1950年创办"长江塑胶厂"
  - 初期生产塑胶玩具/日用品
  - 1957年转型塑胶花生产
  - 获"塑胶花大王"称号

### 2. 地产转型（1960s）
- 1967年香港暴动期间低价收购地产
- 1971年成立"长江实业"
- 1972年上市集资（募资3150万港元）

### 3. 跨国布局（1980s至今）
| 里程碑 | 成就 |
|---------|------|
| 1979年 | 收购和记黄埔（首例华资收购英资洋行） |
| 1986年 | 控股加拿大赫斯基能源 |
| 2010年 | 投资Facebook等科技企业 |

## 三、侨乡情结
**1. 汕头大学建设**  
- 1981年捐资创办（累计捐款超100亿港元）
- 中国唯一私立"211工程"高校
- 医学院附属医院为粤东医疗中心

**2. 潮州公益项目**  
- 捐建"群众医院"、"基础小学"
- 2008年汶川地震捐款1.3亿元
- "李嘉诚基金会"全球医疗教育捐助超300亿

**3. 文化传承**  
- 资助修复潮州古城墙
- 支持潮剧海外巡演
- 2018年回乡祭祖引轰动

## 四、商业哲学
- **潮商精神**  
  "建立自我，追求无我"的潮汕家训
  - 勤奋："别人做8小时，我做16小时"
  - 诚信："你必须以诚待人，别人才会以诚相报"

- **投资智慧**  
  "不赚最后一个铜板"的退出哲学
  - 2013年起陆续出售内地物业
  - 2020年英国资产重组引关注

> "我是潮州人，也是香港人，还是中国人，最终是地球村的成员。"——李嘉诚
