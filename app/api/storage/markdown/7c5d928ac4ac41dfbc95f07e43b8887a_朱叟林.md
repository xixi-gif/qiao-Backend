# 朱叟林：澄海早期的共产党员和革命者[^104^]

## 人物简介
- **基本信息**：
    - **姓名**：朱叟林（又名朱璧图、朱进）
    - **出生日期**：1900年
    - **逝世日期**：1974年3月11日
    - **籍贯**：广东省汕头市澄海区隆都镇溪尾村
- **身份与地位**：朱叟林是澄海县较早的共产党员和党团创建人之一[^104^]。

## 早年经历
- **求学与思想启蒙**：
    - 1922年，朱叟林到上海大同大学读书，期间接受了马列主义理论的熏陶，并积极参加了反帝斗争[^104^]。
    - 1925年，朱叟林从上海回到汕头，受中共广东区汕头支部和共青团汕头地委派遣，到澄海负责开展共青团工作[^104^]。

## 革命活动与贡献
### 一、共青团与党组织建设
- **建立共青团小组与团支部**：
    - 1925年8月，朱叟林以澄海凤山小学（即县立第一高等小学）校长的身份，在澄海建立了共青团小组[^104^]。
    - 1925年12月上旬，在凤山小学成立了澄海第一个团支部——共青团澄海支部，朱叟林担任书记[^104^]。
- **建立中共澄海支部**：
    - 1926年1月上旬，经中共潮梅特委批准，澄海党团组织分开，在凤山小学成立澄海第一个党支部——中共澄海支部（党员10多人），朱叟林担任支部书记[^104^]。
    - 同年，朱叟林被调任中共潮安县委书记[^104^]。

### 二、大革命失败后的活动
- **避居泰国**：大革命失败后，朱叟林避居泰国[^104^]。
- **抗日战争爆发后的回国抗日**：
    - 抗日战争爆发后，朱叟林同侄儿朱维崧回国，奔赴延安参加抗日，转战于冀中、冀南一带[^104^]。

### 三、抗日战争胜利后的活动
- **重返泰国**：抗日战争胜利后，朱叟林重返泰国[^104^]。
- **中华人民共和国成立后回国**：中华人民共和国成立后，朱叟林回国定居[^104^]。

## 总结
朱叟林是澄海县早期的共产党员和革命者，他为澄海县的党团组织建设做出了重要贡献。在大革命失败后，他避居泰国，但抗日战争爆发后，他毅然回国参加抗日。朱叟林的一生，是为革命事业不懈奋斗的一生，他的事迹激励着后人继续前行[^104^]。
