# 家族故事：抓机遇守诚信，贫穷小贩晋身商界巨贾

## 一、发迹历程：从贫穷小贩到商界巨贾

### 萧钦的起点

萧钦，出生于潮阳棉城，幼年家境贫寒，早年于棉城码头以小贩身份谋生，后投身老木匠门下学习木工技艺。略有积蓄后，他毅然前往汕头埠，开设木器店，逐步涉足承建外商土木结构楼房（即"番仔楼"）的领域。

### （一）诚信立业，奠定根基

- **初涉困境**：首次承接英商"番仔楼"工程时，因未能满足业主要求，工程进展不顺。  
- **二次返工**：面对挫折，萧钦选择返工重建，然而第二次依旧未能达标。  
- **三次重建，终获认可**：耗尽积蓄后，他凭借向亲友借款，第三次重建工程，最终成功。尽管此次生意赔本，但他的诚信品质赢得了英商的高度赞赏，被聘为怡和洋行买办。  

### （二）积累经验，蓄势待发

在怡和洋行担任买办期间，萧钦不断积累资金，汲取丰富的营商经验，为日后独立扩大经营实业奠定了坚实基础。  

### （三）多元发展，成就非凡

十九世纪八九十年代，汕头开埠为商业发展带来契机，萧钦敏锐捕捉机遇，在多个领域展开布局：  

- **贸易经营**：开展土特产出口贸易与进口洋货销售业务，同时创办捷盛营造厂。  
- **投资运输**：成立汕潮揭轮船公司，积极开拓近代潮汕地区的内河航运业，实现客货运输在汕头至潮阳、汕头至揭阳之间的常态化运营。  
- **金融合作**：与族人合资开设汕头、揭阳怡和庄银号，发行钞票；同时开办汕头船务行、华资卷烟厂、榨油厂等。  
- **涉足地产**：清光绪年间，借助汕头填海造地扩大街市的契机，投身房地产行业，成为当时汕头颇具影响力的房地产开发商。  

## 二、家族传承：两子皆有建树

### 萧永声

- **职位**：曾担任潮汕铁路公司总经理。  
- **成就**：1906年，在汕头保商局改组为汕头总商会时，凭借出色的能力与威望，被推举为首届总理。  

### 萧永华

- **合作项目**：与高绳芝等人携手合作，共同创办汕头自来水股份有限公司。  
- **职位**：曾担任汕头总商会协理。  
- **成就**：1909年成功当选为广东省咨议局议员。  

## 三、个人雅趣：爱好琴棋书画，汇聚名人雅士

### （一）打造西园，文化胜地

萧钦不惜重金，聘请高人在西园精心设计各种奇趣胜景。园内亭台水榭错落有致，布置了诸多可供宾客挥洒豪情的场景。西园逐渐成为文人雅士的聚集地，他们在此吟诗作画，留下了众多传世佳作。  

### （二）名人交情，墨宝留存

- **广泛结交**：萧钦与康有为、丘逢甲、夏同龢等才俊结下深厚交情，这些名人时常造访西园。  
- **题刻留痕**：西园内的假山石上和楼台匾额题刻，多有康有为、夏同龢、林伯虔、林佐熙等名家的手书，成为西园独特的文化景观。  

### （三）诗作见证，情谊深厚

- **丘逢甲情谊**：丘逢甲对西园喜爱有加，从流传至今的诗作中可见一斑。自1898年3月至1899年6月，短短一年多时间里，他先后为西园留下《西园雅集作》《西园重见诗畸刻本，为之黯然》等38首诗。萧钦母亲71岁寿诞时，丘逢甲还撰写了《诰封夫人萧母姚太夫人七秩开一寿序》一文以表祝贺，足见二人交情之深。  
- **夏同龢墨宝**：作为当朝状元郎的书法名家夏同龢，1899年应萧钦之邀前来潮阳，与丘逢甲、康有为等人一同参观尚在建设之中的西园，为西园留下多处墨宝。1909年，又为竣工的西园补题了门匾，成为西园的文化珍品。  

## 四、公益情怀：热心公益，爱国爱乡

### （一）捐资兴建，造福桑梓

光绪十四年(1888)，萧钦与澄海等地绅商携手，共同捐资兴建汕头同庆善堂，为当地民众提供救助与支持。  

### （二）设立义渡，疏浚城河

- **设立义渡**：在一些地方设立义渡，极大地方便了民众出行。  
- **疏浚城河**：积极疏浚潮阳棉城等地的城河，改善了潮阳、普宁、惠来3县与汕头间的客货运输条件，受到民众的广泛赞扬。  

### （三）家族传承，家风永续

- **萧永声善举**：儿子萧永声也曾于光绪年间义捐，其善举获得朝廷封赐，彰显了家族对公益事业的重视。  
- **萧锡三贡献**：  
  - **留学经历**：嫡孙萧锡三于1920年公派赴法国留学，在国共第一次合作之时，与在法国留学的周恩来同在国民党留法总支部任职，二人交往密切并合影留念。  
  - **教育事业**：1930年，萧锡三回国受聘到中山大学执教。  
  - **抗日贡献**：抗日战争期间，他临危受命，负责组织中山大学的搬迁、疏散工作，不顾个人安危，历经多次辗转，圆满完成迁徙任务。1947年，中大进步师生响应"反内战、反饥饿、反迫害"运动，萧锡三想方设法营救被捕的师生。  
  - **新中国建设**：新中国成立后，他立足本职，教书育人，从事教育事业近半个世纪，以渊博的学识和诚实的品德，为国家培养了一大批科技人才。此外，抗美援朝时期，萧锡三还动员3个成年儿女参军参战。  
  - **家风传承**：如今，西园后裔分布在世界各地，即便身居异国他乡，仍秉承西园传世家风，保持着炽热的爱国爱乡情怀，在不同地方、不同领域为国家及家乡贡献着自己的力量。
