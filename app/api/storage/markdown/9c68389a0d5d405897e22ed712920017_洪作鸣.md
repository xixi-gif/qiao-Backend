# 洪作鸣：“顺琴仙”的传奇人生
洪作鸣，俗名顺琴，被称为“顺琴仙”。之所以获此尊称，是因为他为人谦和，且热心公益，乡人受其诸多恩惠，觉得他有“神仙济世”之胸怀。据东湖村老人回忆，老年的顺琴先生身高一米七八，精神矍铄，留着一截花白胡须，尽显慈祥长者形象。

洪顺琴早年漂泊到越南，当过“咕哩”（码头搬运工），后在当地望族、家乡族人洪良棠家帮工。因其老实忠厚、勤谨有为，深受东家赏识，很快成为得力管家。他与家乡人卓扛（卓厝巷一侨宅主人）合称“扛琴二仙”，共同辅佐东家，助力其事业顺利发展，“扛琴二仙”忠心辅主的故事一时传为佳话。后来，洪顺琴回乡置地建房成家，其住所便是位于后池、一直被人们称作的“顺琴仙厝”。
