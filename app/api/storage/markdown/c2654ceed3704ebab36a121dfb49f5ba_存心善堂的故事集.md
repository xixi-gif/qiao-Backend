__存心善堂的故事集__

__一、创立背景：应时而生的慈善机构__

__（一）汕头埠的慈善需求__

在光绪十四年（1888年），汕头埠已经有了同济善堂，但随着大量流动人口涌入汕头，原有的慈善力量逐渐显得不足。到了光绪二十五年（1899年），汕头埠遭遇了严重的鼠疫，疫情的爆发使得街边遗尸众多，急需更多的慈善机构来进行救助。

__（二）赵进华的善举与存心善堂的诞生__

1. __赵进华的恻隐之心__：光绪二十五年（1899年），赵进华（俗名“胶蚤伯”）从潮阳棉城棉安善堂来到汕头埠打工。他看到街边的遗尸，心生怜悯之情，于是从棉安善堂念佛社请来了大峰祖师木雕像。
2. __设立念佛社__：赵进华在汕头埠设坛办起存心善堂念佛社，开始进行慈善活动。
3. __善堂的迁移与筹建__：最初，存心善堂念佛社向同济外局借地设坛，但后来同济外局要收回所用场所，善堂暂迁移至华佗庙内。元兴洋行的商人看到存心善堂的慈善行为后，倡导并得到郭丽州等48家商界名流的支持，开始筹办建堂。
4. __官府的重视与支持__：光绪二十七年（1901年），澄海县正堂出示晓谕，在汕头埠营盘角择地建存心善堂。经过3年的建设，存心善堂于光绪三十年（1904年）落成，建筑面积达1000多平方米。

__二、救灾赈济：存心善堂的慈善实践__

__（一）1922年“八二风灾”救援__

1. __风灾的破坏__：1922年，一场强烈的台风袭击了潮汕地区，造成了巨大的人员伤亡和财产损失。许多房屋被毁，大量人员伤亡，社会陷入了混乱。
2. __存心善堂的救援行动__：在这场灾难中，存心善堂迅速组织救援行动。他们打捞尸体1\.3万具，并施粥救济，救活了百万灾民。这场救援行动充分展示了存心善堂在灾难面前的担当和能力。

__（二）其他救灾行动__

在民国期间，由于军阀混战和天灾人祸的频繁发生，民众生活困苦。存心善堂在海内外各慈善团体和爱国热心人士的支持下，先后成立了多个救助机构，如存心水龙局、存心医院、存心儿童教养院、存心学校、存心施粥局、存心掩埋队、存心救护队和存心义山等，为饥民提供救济，救护难民，收埋无主尸骸。特别是在潮汕三年大饥荒期间，存心善堂的救助行动挽救了无数人的生命。

__三、现代转型：存心善堂的创新发展__

__（一）创办医院与学校__

1. __存心医院__：1929年，存心善堂创办了存心医院，为当地民众提供医疗服务。这标志着存心善堂在慈善事业上的进一步拓展，开始关注民众的健康问题。
2. __存心学校__：1942年，存心善堂创办了存心学校，为贫困儿童提供教育机会。这体现了存心善堂对教育事业的重视，认识到教育对于改善民众生活的重要性。

__（二）设立消防系统__

存心善堂设立了全国第四大消防系统——存心水龙局。这显示了存心善堂在城市安全方面的贡献，他们不仅关注民众的生活困难，还关心民众的生命安全。

__四、跨国网络：存心善堂与海外侨胞的联系__

存心善堂与海外潮侨保持着紧密的联系。例如，在1920年代，越南华侨郭玫委托存心善堂将其亲属的骨灰运回故土安葬。这种跨国的慈善行为不仅体现了存心善堂的影响力，也反映了海外侨胞对家乡的牵挂和对传统文化的尊重。

__五、当代存心善堂：慈善事业的传承与发展__

__（一）停止活动与财产收归国有__

1951年，在新中国的社会主义改造中，存心善堂停止了活动。善堂的财产被收归国有，工作人员如消防队员、医生等则转化为政府的公职人员。存心善堂的原址在后来的几十年里被用于不同的用途，如市红十字会门诊部和市殡葬所。

__（二）恢复运作与机构发展__

2003年7月，经汕头市民政局、市社团局批准，存心善堂作为汕头慈善总会的分支机构恢复运作。恢复后的存心善堂对原来的石刻、木雕、嵌瓷、漆绘等进行了修复，并且建立了养老院、特殊教育学校、文武学校、医院社工服务站等14家实体服务机构，几乎涵盖了社会救助的各个方面。如今，存心善堂继续秉承其慈善宗旨，在全国有大灾大难的地方都能看到他们的身影。
