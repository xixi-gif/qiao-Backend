施锦裕

\# 施锦裕：情系桑梓，大爱无疆

在泰国，有这样一位杰出的华人企业家，他不仅是商业领域的翘楚，更是心系故土、乐善好施的侨领，他就是施锦裕先生。

\#\# 早年经历：贫寒出身，艰苦奋斗

施锦裕先生1926年出生于广东省饶平县钱东镇施厝村。他幼年家境贫寒，父亲早逝，六岁时随母亲到澄海县盐鸿镇上社村的娘家寄居。十多岁时，为了生计，他随母亲漂洋过海到泰国谋生。在泰国，他从最底层的清洁工做起，历尽艰辛，凭借着坚韧不拔的毅力和敏锐的商业头脑，逐步在商界崭露头角，最终创立了“锦裕盛玻璃行有限公司”，生意越做越兴旺，被誉为泰国“玻璃大王”。

\#\# 衣锦还乡：心系故里，反哺家乡

1991年，施锦裕先生怀着对家乡的深深眷恋，偕同夫人陈玩娟女士回到祖国认祖归宗。当他看到家乡虽然发生了巨大变化，但村集体经济仍然比较落后，群众福利未能得到妥善解决时，他便下定决心，要在有生之年为改变家乡面貌做出自己的贡献。他规划了三件大事：尊师重教、兴学育才；尊老敬贤、兴建村老年人活动中心；重修村道，改善村民出行条件。

\#\#\# 尊师重教，兴学育才

施锦裕先生深知教育对于家乡发展的重要性。他独资捐款450多万元，在施厝村新建了锦裕学校。自1992年学校建成交付使用后，他一直关注学校的发展，对学校的建设、修缮、教学设备、办公设备以及学生的校服、奖教奖学等全方位投入。在他的有生之年，多次为学校捐赠，累计约人民币1000万元。在他的支持下，锦裕学校配备了多媒体电教室、电脑速印室、广播室、仪器室、教师会议室、大礼堂等现代化教学设施，校园绿树成荫，布局合理，为施厝村开辟了一片育人沃土。

\#\#\# 尊老敬贤，兴建村老年人活动中心

施锦裕先生深知“尊老敬贤”是中华民族的传统美德。1995年，他投资50万元在施厝村兴建了老年人活动中心，并配套了潮州大锣鼓、音乐器具等设施。村里的老年人有了一个集中活动的场所，闲暇之时，他们可以在这里品茶聊天、弹唱奏乐，享受惬意的晚年生活。施锦裕先生每年还会寄来活动经费，多次回国与村里的老人们欢聚，被乡亲们称赞为“本村老年人的福星”。

\#\#\# 重修村道，造福村民

施锦裕先生看到家乡的村道崎岖狭窄、颠簸不堪，便决定捐资150万元，将原村道加宽铺平成水泥大道，并在道路两边架设路灯。从此，整个村庄夜如白昼，焕发异彩，乡民们无不拍手称快。

\#\# 大爱无疆：助力家乡全面发展

除了对施厝村的建设不遗余力，施锦裕先生还积极支持钱东镇的其他公益事业。他捐资扩建了钱东人民医院，建设了钱东小公园、钱东运动场、钱东镇标等项目。15年来，施锦裕先生在大陆捐资办福利事业累计1400多万元，他的善举得到了中泰两国的一致褒奖，2004年被潮州市授予“荣誉市民”的光荣称号。

施锦裕先生的故事，是一部充满传奇色彩的奋斗史，更是一曲情系桑梓、大爱无疆的赞歌。他用自己的行动诠释了什么是家国情怀，什么是社会责任。他的仁心善举，将永远激励着家乡的人民，成为饶平大地上永不磨灭的丰碑。
