# 侨胞李云经：海外奋斗的坚毅楷模，教子有方的家风传承典范

## 人物简介
**李云经**（1900-1943）：
- 籍贯：广东潮州潮安县
- 身份：教育家、侨乡文化代表人物
- 特殊身份：香港首富李嘉诚之父
- 生平跨度：清末民初至抗日战争时期

## 人生轨迹

### 早年经历（1900-1920）
1. 出生于潮安县书香门第
2. 就读于潮州金山中学
3. 考取省立第二师范学校（现韩山师范学院）

### 教育生涯（1921-1937）
- **潮安小学**校长（1925-1929）
- **庵埠蔚文学校**教务主任（1930-1935）
- 推行"爱国教育"理念
- 培养大批侨乡子弟

### 抗战时期（1937-1943）
1. 1939年潮汕沦陷后携家避居香港
2. 在香港继续从事教育工作
3. 1943年因肺病逝世于香港

## 精神遗产

### 教育理念
- **"立身以立学为先"**的育人思想
- 首创"国语+潮语"双语教学模式
- 注重传统文化与实用技能结合

### 家训传承
- **"失意不灰心，得意莫忘形"**
- **"穷则独善其身，达则兼济天下"**
- 这些理念深刻影响李嘉诚的经商之道

## 历史评价

> "李云经先生代表了一代侨乡知识分子的风骨——在战乱年代坚守教育救国理想，用文化火种照亮无数侨乡子弟的人生道路。"（《潮州教育志》评语）

## 纪念场所
1. 潮州金山中学"云经亭"
2. 韩山师范学院校史馆专柜
3. 香港潮州商会纪念馆
