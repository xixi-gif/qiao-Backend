# 吴清亮：新加坡的 “亚洲漆王”，桑梓情深的爱国爱乡典范
吴清亮，1927年在新加坡出生，祖籍潮安区浮洋镇大吴村，系立时集团、立邦品牌创始人，曾任新加坡吴德南控股、怡隆、立时贸易、日本油漆和亮阁等集团董事主席，业务横跨十一个国家和地区，被称为“亚洲漆王”。多年来，吴清亮虽身在海外，却一直心系祖国、情牵家乡，鼎力支持家乡教育医疗事业和人居环境建设，捐资累计超1亿元人民币，为家乡的经济发展提供有力支持。

## 情系桑梓，助力乡村建设
吴清亮早年失父，与母亲及姐弟相依为命。他奉母至孝，恪遵慈母遗训：“毋忘家国之情，发达之日，对大吴应有援乡之建”，事业有成后，不忘初心，情系桑梓，多次回乡与大吴村乡亲共商文明村创建规划，捐资修筑环乡村道，改建无害化公厕，既方便了村民的生产生活，也改善了村民的出行条件。同时，捐资对大吴村进行绿化美化，提升村容村貌。1995年，大吴村被评为广东省文明村。大吴村村干部吴淙冰说，在吴清亮先生的带动下，越来越多的侨亲和海外侨胞参与大吴乡村建设，为家乡发展出谋献策，村民对此都赞不绝口。

## 倾心教育，捐建多所学校
潮州市松昌中学校园内，苍松翠柏，生机勃发，莘莘学子，书声琅琅。走进教学楼，可以看到“侨心系国 德惠长馨”主题展览，讲述了吴清亮的创业故事和仁心善举。

松昌中学创办于1991年，是吴清亮以父亲吴松昌之名，斥巨资捐建的一所公办普通完全中学，2005年，学校实现高、初中分离，成为一所普通高级中学。2008年，松昌中学被评为广东省国家示范性高中。30多年来，吴清亮对松昌中学不断关爱和扶持，捐资帮助学校建设教学楼、宿舍楼、实验楼等，添置教学办公设备，提供奖教奖学助学基金，为学校的可持续发展奠定基础。

“吴清亮先生对双亲的至孝之情、对父老乡亲的无私善举、对教育的无私奉献精神，令人钦佩。”市松昌中学党委书记、校长李镇坚说，吴清亮先生艰苦创业的奋斗精神和爱国爱家的崇高风范，激励着松昌中学全体教职员工踔厉前进，以更加饱满的热情投身学校发展建设；鼓舞莘莘学子拼搏进取，勤学守纪，成才报国。松昌中学学生吴金榕认为，吴清亮先生爱国爱乡的精神引导广大学子增强责任感和使命感，也让大家明白，无论个人的成就有多大，都不能忘记回馈社会、帮助他人。学生柯佳杭表示，他会珍惜这来之不易的学习环境和机会，努力学习，传承吴清亮先生的奋斗精神，立志成才，为国家、为社会作出新时代青少年应有的贡献。

据了解，吴清亮还捐建大吴小学，后续又捐资易建为松昌小学和松昌实验学校。为了纪念母亲李秀英，吴清亮在大吴村投资建设秀英园、秀英亭等，体现了他不忘先人养育之恩、情牵家国的赤子情怀。

## 施医惠民，捐建医院
吴清亮了解到家乡的父老乡亲求医问药困难，萌生了捐建医院的想法。2003年，他捐资180万元人民币，以其母亲的名义，在大吴村建设秀英医院施医惠民。2006年，吴清亮再次捐资1500万元人民币对医院进行扩建。2010年底竣工后，原位于浮洋集市中心的浮洋中心卫生院迁至秀英医院。

浮洋镇中心卫生院副院长黄伟龙介绍，医院占地面积24亩，建筑面积11000平方米，开设有内、外、妇、儿、眼、中医等临床科室，满足周边群众的医疗需求，解决“就医难、看病贵”等问题。近年来，医院积极争取上级支持，不断加强医疗队伍建设，完善基础配套设施，着力提升医疗服务水平，努力为群众提供更优质的医疗服务。

吴清亮对家乡的善行义举，感动着每一位大吴村村民。“吴清亮先生虽然旅居海外，但不忘桑梓，只要家乡有需要，他总是无私捐建惠民项目。这种精神令人敬佩，值得我们每个人学习。”村民吴焕强说。
