# 《1907-2011年：张恭良与张恭荣兄弟的侨爱故事》

## 摘要

**故事名称**：《1907-2011年：张恭良与张恭荣兄弟的侨爱故事》  
**时间**：1907年至2011年  
**地点**：葛洲村（家乡），泰国（张恭良曾居住地），香港（张恭荣出生地）  
**人物**：张恭良（1907年出生，葛洲村人，后居泰国），张恭荣（1924年出生，香港人，张恭良的弟弟）  
**事件**：张恭良和张恭荣兄弟二人一生致力于家乡的教育和慈善事业。张恭良1980年回乡后倡议并带头捐资兴办葛洲学校，累计捐款2000多万元。张恭荣继承兄长遗志，捐资400多万元兴建葛洲学校，230万元建设葛洲恭荣幼儿园。兄弟二人及其后代持续为家乡的公益事业贡献力量，使葛洲村成为粤东地区唯一的"侨爱新村"。  

## 故事内容

### 一、人物背景

- **张恭良**：1907年出生于葛洲村，后移居泰国。在泰国期间，他积累了丰富的商业经验，成为当地知名企业家。  
- **张恭荣**：1924年出生于香港，是张恭良的弟弟。他在香港长大，继承了兄长的事业和理念，成为一位杰出的慈善家。  

### 二、教育与慈善事业

#### 张恭良
- **1980年回乡**：张恭良在1980年回到家乡葛洲村，看到家乡教育资源匮乏，决定倡议并带头捐资兴办葛洲学校。  
- **累计捐款2000多万元**：他多次捐资，用于学校的建设、设备购置和师资培训，极大地改善了家乡的教育条件。  

#### 张恭荣
- **继承兄长遗志**：张恭荣继承了兄长的慈善理念，继续为家乡的教育事业贡献力量。  
- **捐资400多万元**：他捐资400多万元用于葛洲学校的进一步建设，确保学校的持续发展。  
- **建设葛洲恭荣幼儿园**：张恭荣还捐资230万元建设了葛洲恭荣幼儿园，为家乡的幼儿教育提供了良好的环境。  

### 三、持续贡献

- **家族传承**：张恭良和张恭荣的后代也继承了他们的慈善精神，持续为家乡的公益事业贡献力量。  
- **侨爱新村**：在兄弟二人及其后代的共同努力下，葛洲村成为粤东地区唯一的"侨爱新村"，成为侨胞回馈家乡、推动家乡发展的典范。  

## 侨批故事的意义

### 一、侨爱精神的传承

张恭良和张恭荣兄弟的故事体现了海外侨胞对家乡的深厚情感和无私奉献。他们的侨爱精神不仅体现在对教育和慈善事业的持续投入，还体现在家族传承中，激励着后代继续为家乡的发展贡献力量。  

### 二、教育与发展的推动

兄弟二人通过捐资兴办学校和幼儿园，极大地改善了家乡的教育条件，为家乡培养了大量人才。这种对教育的重视和投入，不仅提升了家乡的整体素质，也为地方经济的发展奠定了坚实的基础。  

### 三、文化认同与社会和谐

张恭良和张恭荣的故事展现了侨胞对家乡文化的认同和传承。他们的善举不仅改善了家乡的物质条件，还促进了社会的和谐与进步，成为侨胞回馈家乡、推动家乡发展的典范。  

## 结语

张恭良和张恭荣兄弟的侨爱故事，是海外侨胞回馈家乡、推动家乡发展的生动写照。他们的善举不仅改善了家乡的教育条件，还促进了社会的和谐与进步，成为侨胞精神的象征。这种侨爱精神将继续激励着更多的侨胞为家乡的发展贡献力量。
