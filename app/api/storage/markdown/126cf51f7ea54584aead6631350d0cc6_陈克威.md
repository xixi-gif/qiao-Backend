# 陈克威：从潮汕少年到法国华人首富

## 一、个人背景
- **出生背景**：陈克威，1934年生于老挝百细市一个潮汕籍华人家庭，祖籍广东普宁大长陇村。他父亲陈仲卿14岁从潮汕老家漂洋过海到泰国打工，后在老挝定居，靠小本生意为生。

## 二、早年经历
### （一）少年从商
- 陈克威是家中的长子，1952年，17岁的他看到父亲刚过40岁就因操劳过度累弯了腰，毅然放弃高中学业，接管杂货铺，后又做起木材生意，与父亲共同负担起家庭的重担。
- 他继承了潮汕人“宁可睡地板，也要当老板”的执拗精神，在两年内将木材厂工人扩充至350人，后又在碾米厂、味精厂、拖鞋厂等领域开疆拓土。

### （二）遭遇动荡
- 1975年，老挝革命改换政权，新政权严重打击华人，没收华商资产，封闭华人工厂、商店等。陈克威在老挝的所有事业几乎在一夜之间化为乌有，他不得不离开老挝，前往法国寻求发展。

## 三、法国创业历程
### （一）初到法国
- 初到法国时，陈克威和弟弟陈克华、陈克光在巴黎第十二区租了30平米的铺面，想开中式餐馆，但因经验不足，还没开张就被迫关停，投入打了水漂。

### （二）创建“陈氏兄弟公司”
- **公司成立**：1975年，陈克威和弟弟陈克华到法国寻求发展。1976年6月，“陈氏兄弟公司”在巴黎12区开业，起初从事中国及亚洲食品的进口与批发。
- **早期困难**：起初因对法国市场不甚了解，没有固定客户，经常赔钱。兄弟二人不断总结经验，采取小批量进货、边卖边进的做法，逐渐开通发展道路。
- **抓住机遇**：上世纪70年代末，大批东南亚难民到法国定居，带来了亚洲文化和饮食习惯，为“陈氏兄弟公司”提供了商机。公司迅速扩大经营规模和方式，由批发改为批发和零售并举。

### （三）开设陈氏百货商场
- 1981年8月15日，巴黎第一家专营亚洲产品的超级市场——陈氏百货商场在十三区正式开业，此后公司业务稳步发展。到1987年，公司营业额已达2.7亿法郎，被列入法国大型商业企业行列，成为首家被列入法国企业名单的华人企业。

### （四）公司发展壮大
- 1991年，公司营业额超过7亿法郎，在法国批发及进口业“龙虎榜”中名列第122位，被公认为法国及至欧洲最大的华人企业。到2000年，公司营业额已超过10亿法郎。陈克威被法国权威经济杂志列为法国商界第152位、大巴黎地区各行业第359位，跻身法国著名大企业家行列。
- 从1978年起，陈氏公司先后投资700万法郎购置美国IBM电脑系统，实行账目、发票、文书工作电脑化以及法文、中文并用的程序，管理水平跨入现代化企业先进行列。

## 四、社会贡献
### （一）投身慈善公益
- 陈克威积极参与慈善活动，多次为法国及中国的灾区人民捐款。例如，1998年，他代表陈氏公司向中国遭受特大洪水的灾区捐款100万法郎。
- 他还参与了多项社会公益活动，如2003年在华进会和陈氏公司的召集下，近千位旅法华人来到诺莱特华工墓园举行公祭活动。

### （二）推动中法文化交流
- 陈克威的公司不仅在商业上取得了巨大成功，还极大地促进了亚洲食品及文化在欧洲的传播。他推动了央视4套在法国落地，旗下的陈氏传媒成为中法电视节目双向交流的重要媒介。
- 多年来，陈氏兄弟将产自中国及东南亚的食品百货源源不断地输往法国，不仅满足了当地华人的需求，也促进了中法文化交流。

## 五、商业成就与影响
- **商业成就**：陈克威与弟弟陈克光一起，将陈氏兄弟公司发展成为西欧最大的华商企业之一，在法国500强企业中排名靠前。
- **行业影响**：陈氏兄弟公司在法国批发及进口业中具有重要地位，法国及西欧各地的华裔老板们经营的副食、百货等，几乎都与陈氏兄弟公司有业务往来。
- **精神传承**：陈克威的创业故事体现了潮汕人吃苦耐劳、勇于拼搏的精神，成为欧洲华商的精神图腾。

陈克威从一名潮汕少年到法国华人首富，凭借坚韧不拔的毅力和卓越的商业智慧，在异国他乡书写了传奇篇章。他不仅在商业上取得了巨大成功，还为中法文化交流和华人社区的发展做出了积极贡献，成为法国华人界的杰出代表和潮汕人的骄傲。
