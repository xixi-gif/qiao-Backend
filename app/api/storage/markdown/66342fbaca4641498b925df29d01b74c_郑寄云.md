# 华侨故事：爱国侨领排难解纷驰誉侨社

## 一、郑寄云：爱国侨领排难解纷驰誉侨社

### 人物简介

- **郑寄云**：旅泰企业家，爱国华侨，泰国潮州会馆第三届主席。
- **早年经历**：郑寄云早年与父亲在南洋经商有成后返乡捐官建宅，因生意原因往返于冠山与泰国两地。

### 潮州会馆的艰难岁月

- **会馆成立**：泰国潮州会馆成立于1938年，第一届主席由著名侨界领袖陈景川担任。
- **抗战爆发**：全民族抗战爆发后，潮州会馆成为团结旅泰潮人进行抗日救亡的爱国团体。
- **侨领牺牲**：1939年11月21日，会馆发起人之一蚁光炎在曼谷被暗杀。1942年2月，潮州会馆主席陈景川和其他侨领被日军逮捕入狱，会馆一时陷入停顿。
- **馆址危机**：日本占领下的泰国当局以会馆无人负责为借口，通知要征收会馆馆址，企图扼杀该华侨组织。

### 郑寄云的领导

- **临危受命**：在此形势之下，潮属各侨领共商对策，推出德高望重、老成忠厚的郑寄云担任泰国潮州会馆第三届主席。
- **救济侨胞**：郑寄云领导下的潮州会馆，承担了救济与安置在各地逃难出来的侨胞。期间又发生了数十年未遇的水灾，潮州会馆积极组织开展了各项救灾工作。
- **侨社声誉**：在艰难的时局中，郑寄云始终为解决侨胞在异国他乡遇到的各种问题而不辞辛劳，深为旅泰侨胞所敬仰，因其为人忠厚、排难解纷才干驰誉侨社，被尊称为"合兴爷""和事佬"。

## 二、郑肃恭：旅欧医学博士默默支持抗战

### 人物简介

- **郑肃恭**：郑寄云之子，旅欧医学博士、爱国华侨。
- **留学经历**：1923年，郑肃恭与同乡的许包野等中国学生前往德国留学。从珍藏照片资料可知，旅欧期间，郑肃恭、许包野与周恩来、朱德等常有往来。
- **志同道合**：许包野于1923年经朱德介绍加入中国共产党，编入旅欧支部，后回国参加革命活动，被誉为"革命圣火接引人"。郑肃恭与一帮旅欧知识青年志同道合，都在努力学习西方学术，以求强国救民之策。
- **医学成就**：在父亲的支持下，郑肃恭刻苦学习医学知识，在德国获得医学博士，返回泰国之后开办了"南国"药房，以"为病患解除病痛，救死扶伤"为己任，用旅欧所学之医术治病救人。
- **抗战贡献**：抗战期间，郑肃恭也在背后做了不少努力，为中国抗战尽一份力。

## 三、郑松涛：红色足迹与革命先烈

### 人物简介

- **郑松涛**（1918---1940年）：郑寄云之孙、郑肃恭之子，共产党员，抗日英烈。
- **早期经历**：1918年生于泰国，1930年在曼谷后新民学校读书，毕业后回国就读于汕头礐光中学。1935年12月9日，北平爆发抗日救国运动后，激发起郑松涛抗日救国的革命热情，他决心投身抗日救亡斗争中，于是毅然离开汕头，与友人同赴上海，考进上海美术专科学校西洋画系。

### 抗日活动

- **青抗会成立**：1937年8月，汕头青年救亡同志会成立，并派出工作队到潮属各县开展抗日救亡宣传活动。同年9月18日，郑松涛、王慕真、陈锐志、柳润、杨君勉等人在澄城扬祖祠成立澄海青年救亡同志会（1938年统一改称"青年抗敌同志会"）。
- **经济支持**：初期，青抗会活动经费十分困难，家中经济宽裕的郑松涛经常慷慨解囊资助青抗会开展工作，青抗会的工作也随形势发展逐渐由城镇转向农村。
- **组织活动**：在中共党组织的领导下，郑松涛在冠山组织了青抗、妇抗和少工队，他的胞弟松芝、松楠和堂弟柏秋都加入少工队，教唱抗日歌曲，张贴抗日标语，组织传统节日"提灯会"和街头演出等活动，培养骨干力量。冠山的罗列、许杰等少工队员，后来都走上革命道路，成为革命干部。
- **活动基地**：在此期间，郑松涛的家成了澄海青抗会和少工队的活动基地，队员们常在他家食宿。在他的影响下，他的母亲和家人也十分热情地接待往来同志。在经济上无私地支持抗日活动。

### 英勇牺牲

- **被捕经过**：1939年5月，汕头青抗会为适应形势发展，组织了一支以20多名少工队员为主体的抗日儿童流动剧团，郑松涛在该团担任队长，巡回于潮汕各县宣传抗日。1940年4月27日凌晨3时许，日寇与伪军300多人分三路进犯包围县战工队驻地------澄海莲阳北李（现莲上镇南徽村）李氏宗祠，在这危急关头，郑松涛不顾自身安危，协助多名队员越墙转移后，敌人已进入驻地搜查。此时他只要越墙而过，就能顺利脱险。可他毅然把生的希望让给同志，把死的威胁留给自己。
- **英勇就义**：看着还未脱险的4名女队员，他镇定地让女队员踏上自己肩膀越墙，因女队员慌乱而耽搁时间，郑松涛不幸被日寇逮捕。面对日寇的威逼利诱，郑松涛毫不屈服，敌人恼羞成怒，最后残忍地将他押到庵埠赐茶渡亭附近斩首，牺牲时年仅22岁。
- **纪念活动**：中华人民共和国成立后，人民政府追认郑松涛为革命烈士。2000年澄海冠山社区和一批老干部集资在平山仔西南面修建"听涛亭"，以纪念郑松涛烈士。2015年央视《华人世界》栏目以《泰国归侨郑松涛：牺牲前高喊"中国抗战必胜"》为题，详细记录了郑松涛烈士的英勇事迹。

## 四、结语

郑寄云、郑肃恭、郑松涛三代人，分别代表着三个不同时代的华侨人物。他们从清末下南洋经商，到民国时期旅欧求学，再到抗战时期赤诚报国，展现了潮汕华侨的爱国情怀和奋斗精神。他们的故事不仅是个人的传奇，更是潮汕华侨群体的缩影，激励着后人继续传承和弘扬这种精神。

（资料来源：实地走访、郑寄云及郑松涛烈士相关档案）
