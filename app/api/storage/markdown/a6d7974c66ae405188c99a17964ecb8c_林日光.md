# 林日光：金融界精英与泰国经济发展功臣
林日光，林来荣先生之子，1932年出生，是金融界著名人士、原泰国副总理兼财政部部长。

林日光自幼好学不倦，学术成就斐然，先后获得朱拉隆功大学商业学学士、美国密歇根大学工商管理学荣誉硕士、经济学硕士以及工商业管理学博士学位。

在职业生涯中，他担任众多重要职位：曾任协联集团辖下公司董事长、亚洲行政院理事团理事长、国家机构方面顾问团委员等；先后任职东协金融与银行业委员会主席、国家发展经济与社会委会委员、泰国工业公会副主席、国务院财经与政治顾问、泰国促进工业投资委员会秘书长， 同时还担任国家彩票局、储蓄银行、泰京银行等单位的董事长。

林日光对泰国经济事业作出重大贡献，凭借卓越成就，曾先后荣获泰皇上御赐特等白象、特等皇冠、一等白象、一等皇冠和拉宗皓等多枚勋章。
